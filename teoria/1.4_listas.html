1.4. Listas

Hasta ahora hemos guardado cada dato en una variable distinta. Sin embargo, cuando trabajamos con los precios de varias sesiones o con los valores de una cartera, resulta más práctico reunir los datos relacionados en una única colección. En esta lección aprenderás a crear listas, consultar y modificar sus elementos y realizar cálculos sencillos con ellas.

1. Crear una lista

Una lista es una secuencia ordenada de valores. Se escribe entre corchetes, [ ], y sus elementos se separan con comas. El orden importa: en una lista de precios, cada posición puede representar una sesión diferente.

Código
precios_cierre = [101.20, 102.45, 100.80, 103.10, 104.25]
tickers = ["SAN", "BBVA", "IBE"]

print(precios_cierre)
print(tickers)
print(type(precios_cierre))
Resultado
[101.2, 102.45, 100.8, 103.1, 104.25]
['SAN', 'BBVA', 'IBE']
<class 'list'>

La primera lista contiene números decimales y la segunda contiene texto. Python también permite mezclar tipos de datos dentro de una misma lista, aunque normalmente una serie de precios o una lista de tickers resulta más fácil de interpretar si todos sus elementos representan la misma clase de información.

Una lista sin elementos se denomina lista vacía y se crea escribiendo simplemente []. Más adelante podremos añadirle valores.

2. Conocer la longitud de una lista

La función len() devuelve el número de elementos de una lista. En el siguiente ejemplo, ese número coincide con la cantidad de sesiones para las que hemos guardado un precio de cierre.

Código
precios_cierre = [101.20, 102.45, 100.80, 103.10, 104.25]
numero_sesiones = len(precios_cierre)

print(numero_sesiones)
Resultado
5

3. Acceder a los elementos mediante índices

Cada elemento de una lista tiene asociada una posición, llamada índice. Python empieza a contar desde cero: el primer elemento tiene el índice 0, el segundo el índice 1 y así sucesivamente. Para acceder a un elemento, escribimos el nombre de la lista seguido de su índice entre corchetes.

Código
precios_cierre = [101.20, 102.45, 100.80, 103.10, 104.25]

print(precios_cierre[0])
print(precios_cierre[2])
Resultado
101.2
100.8

Como la lista tiene cinco elementos, sus índices positivos van de 0 a 4. El último índice es siempre uno menos que la longitud de la lista.

Valor 101.20 102.45 100.80 103.10 104.25
Índice positivo01234
Índice negativo-5-4-3-2-1

También podemos contar desde el final mediante índices negativos. El índice -1 señala el último elemento, -2 el penúltimo y así sucesivamente. Esta forma es especialmente útil cuando la longitud de la lista puede cambiar.

Código
precios_cierre = [101.20, 102.45, 100.80, 103.10, 104.25]

print(precios_cierre[-1])
print(precios_cierre[-2])
Resultado
104.25
103.1

4. Seleccionar varios elementos con slicing

El slicing permite extraer una parte de una lista. Para indicar el comienzo y el final del corte utilizamos lista[inicio:fin]. El elemento situado en inicio se incluye, pero el elemento situado en fin queda fuera.

Código
precios_cierre = [101.20, 102.45, 100.80, 103.10, 104.25]

print(precios_cierre[0:3])
print(precios_cierre[:3])
print(precios_cierre[-2:])
print(precios_cierre[2:])
Resultado
[101.2, 102.45, 100.8]
[101.2, 102.45, 100.8]
[103.1, 104.25]
[100.8, 103.1, 104.25]

Si omitimos el índice inicial, Python empieza desde el principio; si omitimos el índice final, continúa hasta el último elemento. Por eso precios_cierre[:3] selecciona los tres primeros precios y precios_cierre[-2:] selecciona los dos últimos.

Un slice produce una lista nueva con los elementos seleccionados. La lista original no cambia.

5. Modificar elementos

Las listas son mutables: podemos cambiar sus elementos después de crearlas. La asignación se realiza utilizando el índice de la posición que queremos actualizar.

Código
precios_cierre = [101.20, 102.45, 100.80, 103.10, 104.25]
precios_cierre[2] = 101.05

print(precios_cierre)
Resultado
[101.2, 102.45, 101.05, 103.1, 104.25]

En este caso hemos corregido el tercer precio. La lista sigue teniendo cinco elementos; únicamente ha cambiado el valor que ocupaba el índice 2.

6. Añadir y eliminar elementos

Las listas disponen de métodos para realizar operaciones habituales. Como vimos al trabajar con funciones, un método se llama escribiendo el nombre del objeto, un punto y el nombre del método. Por ejemplo, tickers.append("ITX") llama al método append() de la lista tickers.

Código
tickers = ["SAN", "BBVA", "IBE"]

tickers.append("ITX")
print(tickers)

tickers.remove("BBVA")
print(tickers)

ultimo_ticker = tickers.pop()
print(ultimo_ticker)
print(tickers)
Resultado
['SAN', 'BBVA', 'IBE', 'ITX']
['SAN', 'IBE', 'ITX']
ITX
['SAN', 'IBE']
Método Qué hace
lista.append(valor)Añade valor al final de la lista.
lista.remove(valor)Elimina la primera aparición de valor.
lista.pop()Elimina el último elemento y lo devuelve.
lista.index(valor)Devuelve el índice de la primera aparición de valor.

append() y remove() modifican la propia lista. pop() también la modifica, pero además devuelve el elemento eliminado, por lo que podemos guardarlo en una variable. Si necesitas recordar el funcionamiento de cualquiera de estos métodos, puedes consultar su documentación con una llamada como help(tickers.append).

7. Comprobar si un valor pertenece a una lista

El operador in comprueba si un valor aparece en una lista y devuelve un booleano. El operador not in realiza la comprobación contraria. Podemos utilizar ambos resultados directamente o incorporarlos a las estructuras condicionales de la lección anterior.

Código
cartera = ["SAN", "IBE"]

print("SAN" in cartera)
print("BBVA" in cartera)
print("ITX" not in cartera)

if "SAN" in cartera:
    print("SAN está en la cartera")
Resultado
True
False
True
SAN está en la cartera

8. Cálculos básicos con listas numéricas

Varias funciones incorporadas de Python permiten resumir una lista de números. min() devuelve el valor mínimo, max() el máximo y sum() suma todos los elementos. Combinando sum() y len() podemos calcular la media.

Código
precios_cierre = [101.20, 102.45, 100.80, 103.10, 104.25]

print(min(precios_cierre))
print(max(precios_cierre))
print(sum(precios_cierre))

precio_medio = sum(precios_cierre) / len(precios_cierre)
print(precio_medio)
Resultado
100.8
104.25
511.8
102.36

La función sorted() devuelve los elementos ordenados en una lista nueva. De forma predeterminada, los números se ordenan de menor a mayor y el contenido de la lista original permanece sin cambios.

Código
precios_cierre = [101.20, 102.45, 100.80, 103.10, 104.25]
precios_ordenados = sorted(precios_cierre)

print(precios_ordenados)
print(precios_cierre)
Resultado
[100.8, 101.2, 102.45, 103.1, 104.25]
[101.2, 102.45, 100.8, 103.1, 104.25]

9. Ejemplo completo: analizar las últimas sesiones

Podemos combinar el slicing y las funciones anteriores para analizar solo una parte de los datos. En este ejemplo seleccionamos las tres sesiones más recientes y calculamos su precio mínimo, su precio máximo y su media.

Código
precios_cierre = [98.50, 99.20, 100.10, 99.80, 101.30, 102.00]

ultimas_tres = precios_cierre[-3:]
precio_minimo = min(ultimas_tres)
precio_maximo = max(ultimas_tres)
precio_medio = sum(ultimas_tres) / len(ultimas_tres)

print(ultimas_tres)
print(precio_minimo)
print(precio_maximo)
print(round(precio_medio, 2))
Resultado
[99.8, 101.3, 102.0]
99.8
102.0
101.03

El índice negativo evita que tengamos que conocer la longitud total de la lista para quedarnos con los tres últimos valores. Después, todas las funciones trabajan sobre ultimas_tres, no sobre la serie completa.

10. Introducción a las listas anidadas

Una lista también puede contener otras listas. A esta estructura la llamamos lista anidada. Por ejemplo, podemos representar una cartera sencilla mediante una lista exterior en la que cada elemento es otra lista con el ticker, el número de acciones y el precio de compra de un activo.

Código
cartera = [
    ["SAN", 25, 4.58],
    ["IBE", 10, 12.40],
    ["ITX", 5, 47.20]
]

print(cartera[0])
print(cartera[0][0])
print(cartera[0][1])
Resultado
['SAN', 25, 4.58]
SAN
25

cartera[0] selecciona la primera lista interior completa. Para acceder a un dato concreto utilizamos dos índices: cartera[0][0] selecciona primero el primer activo y después su ticker, mientras que cartera[0][1] obtiene el número de acciones.

Resumen

  • Las listas guardan una secuencia ordenada de valores y se escriben entre corchetes.
  • len() devuelve el número de elementos de una lista.
  • Los índices positivos empiezan en 0 y los negativos permiten contar desde el final.
  • El slicing selecciona una parte de la lista sin modificar la original.
  • Las listas son mutables: podemos cambiar, añadir y eliminar elementos.
  • in y not in comprueban si un valor pertenece a una lista.
  • min(), max(), sum(), len() y sorted() permiten obtener información y realizar cálculos básicos.
  • Una lista puede contener otras listas para representar datos con varios niveles.
