1.7. Módulos y bibliotecas externas

Hasta ahora hemos trabajado principalmente con funciones y tipos incorporados en Python. Sin embargo, una de sus mayores ventajas es la enorme cantidad de código reutilizable disponible en módulos y bibliotecas. En esta lección aprenderás a importarlos, explorar lo que ofrecen y reconocer los objetos nuevos que incorporan.

1. Módulos y bibliotecas

Un módulo es un archivo de Python que agrupa funciones, variables y otros objetos relacionados. En lugar de volver a escribir ese código, podemos importarlo y utilizarlo en nuestro programa.

Una biblioteca es un conjunto más amplio de código preparado para resolver tareas de un determinado ámbito. Puede estar formada por varios módulos y submódulos. Por ejemplo, Matplotlib es una biblioteca de visualización y matplotlib.pyplot es uno de sus submódulos.

Las funciones print(), len() o round() están incorporadas en Python y se pueden utilizar directamente. En cambio, para acceder al contenido de un módulo debemos importarlo primero.

2. Importar un módulo con import

Python incluye una biblioteca estándar disponible en cualquier instalación. Uno de sus módulos es math, que contiene funciones y constantes matemáticas. La instrucción import math carga el módulo y crea el nombre math en nuestro programa.

Código
import math

print(type(math))
Resultado
<class 'module'>

La importación suele escribirse al principio del programa o del notebook. Solo necesitamos ejecutarla una vez durante la sesión para empezar a utilizar el contenido del módulo.

3. Acceder a funciones y atributos

Los nombres definidos dentro de un módulo se consultan mediante un punto. Algunos representan valores, como math.pi, y otros representan funciones, como math.sqrt() o math.log().

Código
import math

print(round(math.pi, 4))
print(math.sqrt(144))
print(math.log(8, 2))
Resultado
3.1416
12.0
3.0

El prefijo math. indica claramente de dónde procede cada nombre. Esta separación evita que las variables y funciones de distintos módulos se confundan entre sí.

4. Utilizar un alias con as

Podemos asignar un nombre más corto al módulo mediante as. El alias no modifica la biblioteca; solo establece el nombre que utilizaremos durante esa sesión.

Código
import math as m

print(m.sqrt(81))
print(round(m.pi, 3))
Resultado
9.0
3.142

Después de import math as m, accedemos al módulo mediante m. En las bibliotecas de análisis de datos existen alias aceptados por convención, como np para NumPy y pd para Pandas. Utilizarlos facilita que otras personas reconozcan el código.

5. Importar elementos concretos

Si solo necesitamos unos pocos elementos, podemos importarlos directamente con from modulo import elemento. A partir de ese momento se utilizan sin escribir el nombre del módulo delante.

Código
from math import sqrt, pi

print(sqrt(25))
print(round(pi, 2))
Resultado
5.0
3.14
Evita from modulo import *: esta forma importa todos los nombres sin indicar su procedencia. Si dos módulos contienen una función con el mismo nombre, la última importación puede sustituir a la anterior y producir resultados difíciles de interpretar. Es preferible importar el módulo completo o indicar los elementos concretos.

6. Biblioteca estándar y bibliotecas externas

Los módulos de la biblioteca estándar se distribuyen con Python. Podemos utilizarlos sin instalar nada adicional. Las bibliotecas externas son proyectos independientes que deben estar instalados en el entorno antes de importarlos.

Procedencia Ejemplos Disponibilidad
Biblioteca estándarmath, statistics, datetime, randomSe instala junto con Python.
Bibliotecas externasNumPy, Pandas, Matplotlib, Seaborn, scikit-learnDeben estar instaladas en el entorno.

Google Colab incluye de antemano muchas bibliotecas de análisis de datos. En otros entornos puede ser necesario instalarlas antes de ejecutar el import. La instalación y la importación son pasos diferentes: instalar hace que la biblioteca esté disponible; importar permite utilizarla en el programa actual.

7. Explorar con type(), dir() y help()

Cuando trabajamos con un módulo u objeto desconocido, tres funciones incorporadas nos ayudan a orientarnos:

Función Pregunta que responde
type(objeto)¿Qué tipo de objeto es?
dir(objeto)¿Qué nombres, atributos y métodos contiene?
help(objeto)¿Cómo se utiliza y qué argumentos acepta?
Código
import math

print(type(math))
print(type(math.pi))
print(callable(math.sqrt))
print("sqrt" in dir(math))
Resultado
<class 'module'>
<class 'float'>
True
True

dir(math) devuelve una lista larga, por lo que en el ejemplo comprobamos si contiene el nombre "sqrt". Una vez localizada una función prometedora, podemos consultar su documentación:

Código
import math

help(math.sqrt)

La ayuda muestra la firma de sqrt(), los argumentos que recibe y una descripción. El mismo proceso funciona con módulos completos, funciones, métodos y objetos creados por bibliotecas externas.

8. Objetos nativos y objetos de una biblioteca

Las bibliotecas pueden definir sus propios tipos. Pandas proporciona objetos Series y DataFrame; Matplotlib, figuras y ejes; NumPy, arrays. Estos objetos pueden utilizar métodos y operadores de una forma distinta a los tipos nativos.

El siguiente ejemplo compara una lista de Python con un array de NumPy:

Código
import numpy as np

precios_lista = [100, 101, 102]
precios_array = np.array(precios_lista)

print(type(precios_lista))
print(type(precios_array))
print(precios_lista + [1])
print(precios_array + 1)
Resultado
<class 'list'>
<class 'numpy.ndarray'>
[100, 101, 102, 1]
[101 102 103]

En una lista, + une dos listas. En un array, + 1 suma uno a cada elemento. Es el mismo operador, pero cada tipo define su comportamiento. Por eso conviene utilizar type(), consultar la documentación y no asumir que un objeto externo funciona exactamente como una lista.

Las siguientes bibliotecas son habituales en análisis de datos y aparecerán en el próximo bloque del curso:

10. Leer mensajes de error relacionados con importaciones

Cuando una importación o una consulta falla, la última línea del mensaje suele contener el tipo de error y una descripción breve. Esa línea es el primer lugar que conviene leer.

Error Causa habitual Qué revisar
ModuleNotFoundErrorEl módulo no está instalado o su nombre está mal escrito.El nombre de la biblioteca y el entorno utilizado.
NameErrorSe utiliza un nombre que no existe en la sesión.Si se ejecutó el import y si se está usando el alias correcto.
AttributeErrorEl módulo u objeto no contiene el atributo solicitado.La ortografía y el resultado de dir().
TypeErrorUna función recibe argumentos incompatibles.La firma mostrada por help() y los tipos de los argumentos.

Por ejemplo, el módulo math no contiene una función llamada raiz_cuadrada:

Código
import math

math.raiz_cuadrada(9)
Mensaje de error
AttributeError: module 'math' has no attribute 'raiz_cuadrada'

El mensaje identifica el módulo y el nombre que no ha encontrado. Podemos consultar dir(math) o la documentación para localizar la función correcta, math.sqrt().

11. Ejemplo completo: utilizar un módulo desconocido

Supongamos que queremos obtener la media y la mediana de una lista de precios. El módulo statistics de la biblioteca estándar ofrece funciones para estos cálculos. Podemos importarlo con un alias, comprobar qué contiene y utilizar sus funciones.

Código
import statistics as stats

precios_cierre = [101.20, 102.45, 100.80, 103.10, 104.25]

print("mean" in dir(stats))

media = stats.mean(precios_cierre)
mediana = stats.median(precios_cierre)

print(f"Media: {media:.2f}")
print(f"Mediana: {mediana:.2f}")
Resultado
True
Media: 102.36
Mediana: 102.45

Este proceso se repite al descubrir una biblioteca nueva: importamos, comprobamos el tipo de los objetos, exploramos los nombres disponibles y consultamos la ayuda antes de utilizar las funciones elegidas.

Resumen

  • Un módulo agrupa código reutilizable; una biblioteca puede reunir varios módulos y submódulos.
  • import modulo carga un módulo y el punto permite acceder a su contenido.
  • as asigna un alias, mientras que from ... import ... importa elementos concretos.
  • Las importaciones con * pueden provocar conflictos entre nombres.
  • La biblioteca estándar se incluye con Python; las bibliotecas externas deben estar instaladas.
  • type(), dir() y help() ayudan a explorar módulos y objetos desconocidos.
  • Los tipos definidos por una biblioteca pueden dar un significado distinto a operadores y métodos.
  • Los alias habituales incluyen np, pd, plt y sns.
  • La última línea de un error suele indicar su tipo y la causa inmediata.
