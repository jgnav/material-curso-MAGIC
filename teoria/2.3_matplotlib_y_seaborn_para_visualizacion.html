2.3. Matplotlib y Seaborn para visualización

En las lecciones anteriores utilizamos Pandas para organizar datos y NumPy para realizar cálculos numéricos. Ahora partiremos de esos resultados ya preparados para representarlos mediante gráficos. Matplotlib nos permitirá construir y personalizar figuras, mientras que Seaborn facilitará la creación de visualizaciones claras a partir de columnas de un DataFrame.

1. Importar Matplotlib y Seaborn

Matplotlib es la biblioteca de visualización fundamental de Python. Normalmente importamos su módulo pyplot mediante el alias plt. Seaborn se apoya en Matplotlib y se importa habitualmente como sns.

sns.set_theme() aplica un aspecto común a las figuras. Su parámetro style admite opciones como "whitegrid", "darkgrid", "white", "dark" o "ticks". También puede recibir context con valores como "paper", "notebook", "talk" o "poster" para adaptar el tamaño de los elementos al contexto de presentación.

Código
import matplotlib.pyplot as plt
import seaborn as sns

sns.set_theme(style="whitegrid")

Las dos bibliotecas pueden utilizarse juntas: es habitual dibujar con Seaborn y completar títulos, ejes o tamaños mediante Matplotlib.

2. Elegir el tipo de gráfico

Antes de escribir código conviene decidir qué queremos observar. Cada tipo de gráfico responde mejor a una pregunta distinta:

Tipo Pregunta principal Función habitual
Líneas¿Cómo cambia una variable siguiendo un orden, normalmente temporal?plt.plot() o sns.lineplot()
Histograma¿Cómo se distribuyen los valores de una variable numérica?plt.hist() o sns.histplot()
Dispersión¿Qué relación existe entre dos variables numéricas?plt.scatter() o sns.scatterplot()
Mapa de calor¿Qué patrones aparecen en una tabla de valores o correlaciones?sns.heatmap()
Un gráfico ayuda a detectar tendencias, distribuciones y relaciones, pero no sustituye la comprobación numérica. Conviene utilizarlo junto con medidas como la media, la desviación estándar o la correlación.

3. Datos de partida

En esta lección no crearemos ni transformaremos los datos. Partiremos de los siguientes objetos, que ya estarán cargados antes de ejecutar los ejemplos:

Objeto Tipo Contenido disponible
datosDataFrameColumnas Fecha, Cierre y Media_movil_3.
retornosSeriesUna serie numérica preparada para estudiar su distribución.
comparacionDataFrameColumnas Retorno_A, Retorno_B y Periodo.
retornos_activosDataFrameTres columnas numéricas con las que calcular una matriz de correlación.

De este modo, el código de cada apartado se concentra únicamente en representar la información.

4. Representar una serie con Matplotlib

Un gráfico de líneas conecta los valores siguiendo el orden recibido. En el eje horizontal colocaremos las fechas y en el vertical los precios de cierre. Añadiremos también una segunda línea para comparar la serie con su media móvil.

La forma más habitual de utilizar esta función es plt.plot(x, y, ...). Los dos primeros argumentos indican qué datos se colocan en cada eje; el resto permite controlar el aspecto de la línea.

Parámetro Qué controla Opciones habituales
x, yLos valores de los ejes horizontal y vertical.Listas, arrays o columnas de un DataFrame.
colorEl color de la línea.Abreviaturas como "b", "g", "r", "c", "m", "y", "k" o "w".
linestyleEl estilo del trazo."-", "--", ":" o "-.".
linewidthEl grosor de la línea.Un número como 1, 2 o 3.
markerEl símbolo dibujado sobre cada observación."o", "s", "^" o None.
labelEl nombre que se mostrará en la leyenda.Cualquier string descriptivo.

Antes de dibujar utilizaremos plt.figure(figsize=(ancho, alto)) para crear una figura con el tamaño indicado en pulgadas. Después podemos añadir contexto con title(), xlabel() y ylabel(). legend() muestra los textos definidos con label, grid() controla la cuadrícula y show() presenta el resultado.

Código
plt.figure(figsize=(9, 4))

plt.plot(
    datos["Fecha"],
    datos["Cierre"],
    color="b",
    linewidth=2,
    marker="o",
    label="Cierre",
)
plt.plot(
    datos["Fecha"],
    datos["Media_movil_3"],
    color="g",
    linestyle="--",
    label="Media móvil (3)",
)

plt.title("Evolución del precio")
plt.xlabel("Fecha")
plt.ylabel("Precio")
plt.grid(alpha=0.3)
plt.legend()
plt.tight_layout()
plt.show()
Resultado

El resultado permite distinguir las dos series por su color y por su estilo de línea. Los marcadores señalan las observaciones de la serie principal y la leyenda identifica cada elemento sin necesidad de incluir esa información dentro del área de dibujo.

5. Visualizar una distribución con Seaborn

Un histograma agrupa los valores numéricos en intervalos y muestra cuántas observaciones caen en cada uno. sns.histplot() permite añadir una curva de densidad suavizada mediante kde=True.

La función puede recibir directamente una Series o trabajar con una columna de un DataFrame. Sus parámetros principales son los siguientes:

Parámetro Qué controla Opciones habituales
dataLos datos que se van a representar.Una Series, un array o un DataFrame.
xLa columna numérica, si data es un DataFrame.El nombre de una columna.
binsCómo se dividen los valores en intervalos.Un entero, una lista de límites o "auto".
kdeSi se añade una curva de densidad suavizada.True o False.
statLa medida mostrada en el eje vertical."count", "frequency", "density" o "probability".
color, alphaEl color y la transparencia de las barras.Un color y un valor de 0 a 1.

En el ejemplo utilizaremos ocho intervalos y mantendremos el valor predeterminado de stat="count", por lo que la altura de cada barra indicará el número de observaciones.

Código
plt.figure(figsize=(8, 4))
sns.histplot(
    data=retornos,
    bins=8,
    kde=True,
    color="b",
)
plt.title("Distribución de los retornos")
plt.xlabel("Retorno")
plt.ylabel("Frecuencia")
plt.tight_layout()
plt.show()
Resultado

El número de intervalos cambia el nivel de detalle: muy pocos pueden ocultar diferencias y demasiados pueden producir una figura irregular. La curva KDE ayuda a percibir la forma general, pero debe interpretarse junto con las barras y con el número de observaciones disponibles.

6. Comparar dos variables con un gráfico de dispersión

En un gráfico de dispersión, cada punto combina un valor del eje horizontal con otro del eje vertical. sns.scatterplot() permite relacionar esas dos variables y utilizar el color, el tamaño o la forma para incorporar información adicional.

Parámetro Qué controla Opciones habituales
dataEl DataFrame del que se toman las variables.Un DataFrame.
x, yLas variables de los ejes horizontal y vertical.Nombres de columnas numéricas.
hueLa variable que determina el color de cada punto.Una columna categórica o numérica.
styleLa variable que determina la forma del marcador.Normalmente, una columna categórica.
sEl tamaño de todos los puntos.Un número como 40, 70 o 100.
palette, alphaLa paleta de colores y la transparencia.Por ejemplo, "deep" y un valor de 0 a 1.

Cuando usamos hue, Seaborn crea automáticamente una leyenda con las categorías encontradas. En este caso el color distinguirá el periodo al que pertenece cada observación. También fijaremos las posiciones visibles de los ejes mediante xticks() y yticks().

Código
plt.figure(figsize=(6, 5))
sns.scatterplot(
    data=comparacion,
    x="Retorno_A",
    y="Retorno_B",
    hue="Periodo",
    s=90,
)
plt.title("Relación entre dos series por periodo")
plt.xlabel("Retorno A")
plt.ylabel("Retorno B")
plt.xticks([-0.005, 0.000, 0.005, 0.010])
plt.yticks([-0.005, 0.000, 0.005, 0.010])
plt.tight_layout()
plt.show()
Resultado

En el resultado, una nube ascendente sugiere una relación positiva y una descendente, una relación negativa. El color permite comprobar si el patrón cambia entre categorías. El gráfico ayuda a observar relaciones y posibles valores atípicos, pero no demuestra que una variable cause los cambios de la otra.

7. Combinar gráficos con subplots

Una figura es el lienzo completo y cada Axes es una zona de dibujo dentro de ella. plt.subplots() crea ambos objetos y permite colocar varios gráficos de forma ordenada. Seaborn puede dibujar en un Axes concreto mediante el argumento ax.

La llamada plt.subplots(nrows, ncols, ...) define la cuadrícula antes de dibujar. Estos son sus parámetros más útiles al comenzar:

Parámetro Qué controla Ejemplos
nrowsEl número de filas.1, 2, 3...
ncolsEl número de columnas.1, 2, 3...
figsizeEl ancho y el alto de la figura completa.(10, 4) o (8, 6).
sharex, shareySi los gráficos comparten la misma escala en un eje.True o False.

La función devuelve dos elementos: la figura completa y los ejes creados. Al pedir una fila y dos columnas, ejes[0] será la zona izquierda y ejes[1] la derecha. El parámetro ax de las funciones de Seaborn nos permite elegir en cuál de ellas dibujar.

Código
figura, ejes = plt.subplots(
    1,
    2,
    figsize=(12, 4),
)

ejes[0].plot(
    datos["Fecha"],
    datos["Cierre"],
    marker="o",
)
ejes[0].set_title("Serie de precios")

sns.histplot(
    data=retornos,
    bins=8,
    ax=ejes[1],
)
ejes[1].set_title("Distribución de retornos")

figura.suptitle("Resumen de los datos")
figura.tight_layout()
plt.show()
Resultado

Los métodos de cada Axes suelen comenzar por set_, como set_title(). En cambio, suptitle() pertenece a la figura y añade un título común. Finalmente, tight_layout() ajusta el espacio para reducir solapamientos entre títulos, ejes y etiquetas.

8. Visualizar correlaciones con un mapa de calor

La correlación resume la relación lineal entre dos variables mediante un valor situado entre -1 y 1. Una vez calculada la matriz con corr(), sns.heatmap() asigna un color a cada valor y facilita su comparación.

Parámetro Qué controla Opciones habituales
dataLa tabla bidimensional que se representa mediante colores.Un array o un DataFrame numérico.
annotSi se escribe el valor dentro de cada celda.True o False.
fmtEl formato de los valores escritos.".2f" para dos decimales o ".0f" sin decimales.
cmapLa paleta que convierte los números en colores."coolwarm", "viridis" o "Blues".
vmin, vmaxLos extremos de la escala de color.Para correlaciones, normalmente -1 y 1.
centerEl valor que ocupa el centro visual de una paleta divergente.Por ejemplo, 0.
linewidthsLa separación visible entre las celdas.Un número como 0.5 o 1.

En una matriz de correlación conviene mantener una escala fija entre -1 y 1. Así, el mismo color representa siempre el mismo valor y resulta más sencillo comparar diferentes mapas de calor.

Código
correlaciones = retornos_activos.corr()

plt.figure(figsize=(6, 4))
sns.heatmap(
    correlaciones,
    annot=True,
    cmap="coolwarm",
    vmin=-1,
    vmax=1,
    fmt=".2f",
)
plt.title("Correlación entre series")
plt.tight_layout()
plt.show()
Resultado

En el resultado, los tonos cálidos representan correlaciones positivas y los fríos, negativas. La diagonal vale 1 porque cada columna está perfectamente correlacionada consigo misma. Una correlación alta permite describir una relación lineal, pero no implica que una variable cause los cambios de la otra.

9. Buenas prácticas de representación

Una figura útil no necesita reunir todas las opciones disponibles. Debería responder a una pregunta concreta y facilitar la lectura de los datos.

  • Utiliza un título que describa el contenido del gráfico.
  • Nombra los ejes e indica las unidades cuando sean necesarias.
  • Evita añadir demasiadas series, colores o elementos decorativos.
  • Usa una leyenda cuando el gráfico contenga varias series o categorías.
  • Combina colores con marcadores o estilos de línea cuando necesites distinguir elementos con claridad.
  • Revisa que la escala de los ejes no oculte ni exagere las diferencias.
  • Interpreta los patrones visuales junto con los cálculos numéricos.

Resumen

  • Matplotlib se importa habitualmente mediante import matplotlib.pyplot as plt y Seaborn mediante import seaborn as sns.
  • Los gráficos de líneas muestran evolución; los histogramas, distribuciones; y los gráficos de dispersión, relaciones entre variables.
  • figsize controla el tamaño de una figura y title(), xlabel() y ylabel() añaden contexto.
  • label junto con legend() permite identificar varias series.
  • Seaborn trabaja directamente con un DataFrame mediante data y nombres de columnas en x, y o hue.
  • plt.subplots() crea una figura con varias zonas de dibujo.
  • sns.heatmap() representa tablas numéricas mediante colores y resulta útil para visualizar correlaciones.
  • plt.tight_layout() ajusta los márgenes y plt.show() muestra la figura.
