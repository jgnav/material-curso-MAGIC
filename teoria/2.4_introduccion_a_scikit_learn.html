2.4. Introducción a scikit-learn

En las lecciones anteriores hemos preparado datos con Pandas, realizado operaciones con NumPy y representado resultados con Matplotlib y Seaborn. En esta última lección reuniremos esas piezas para construir un primer modelo de aprendizaje supervisado con scikit-learn.

1. Aprender patrones a partir de datos

En el aprendizaje supervisado disponemos de observaciones para las que ya conocemos el resultado. Un modelo utiliza esos ejemplos para aprender una relación entre unos datos de entrada y el valor que queremos predecir. Después puede aplicar la relación aprendida a observaciones que no ha utilizado durante el entrenamiento.

La biblioteca se llama scikit-learn, aunque en las importaciones se escribe sklearn. Sus modelos comparten una interfaz muy consistente, por lo que el flujo de trabajo se mantiene aunque cambiemos de algoritmo:

Paso Pregunta Operación
Preparar¿Qué información utilizará el modelo y qué debe predecir?Definir X e y.
Definir¿Qué tipo de modelo vamos a utilizar?Crear el estimador.
Entrenar¿Qué patrones aparecen en los ejemplos conocidos?fit().
Predecir¿Qué resultado estima el modelo para datos nuevos?predict().
Evaluar¿Hasta qué punto se aproximan las predicciones a los valores reales?Calcular una métrica.

2. Regresión y clasificación

El tipo de modelo depende principalmente de la variable que queremos predecir. En este curso distinguiremos dos tareas supervisadas:

Tarea Resultado Ejemplos de modelos
RegresiónPredice un valor numérico, como 0.008 o 104.5.LinearRegression, DecisionTreeRegressor.
ClasificaciónPredice una categoría, como "Positivo" o "Negativo".LogisticRegression, DecisionTreeClassifier.

Nuestro ejemplo será de regresión, porque la variable objetivo es numérica. El propósito no es obtener un modelo útil para tomar decisiones reales, sino aprender la estructura común de scikit-learn.

4. Separar las variables predictoras y el objetivo

Por convención, llamamos X al conjunto de variables predictoras, también conocidas como features. Debe ser una estructura bidimensional: cada fila es una observación y cada columna, una variable. Llamamos y a la variable objetivo que queremos predecir.

La fecha sirve para ordenar y mostrar los resultados, pero no se la entregaremos al modelo. Seleccionaremos únicamente las tres columnas numéricas preparadas como variables predictoras.

Código
variables = [
    "Retorno_anterior",
    "Media_movil_3",
    "Volatilidad_3",
]

X = datos_modelo[variables]
y = datos_modelo["Retorno_siguiente"]

print(X.shape)
print(y.shape)
Resultado
(16, 3)
(16,)

X tiene dieciséis filas y tres columnas. y contiene los dieciséis resultados asociados. Ambos objetos deben conservar el mismo orden: la fila de una observación en X corresponde al valor situado en la misma posición de y.

5. Separar entrenamiento y prueba de forma cronológica

Evaluar el modelo con los mismos datos utilizados para entrenarlo puede producir una impresión engañosa. Un modelo podría recordar los ejemplos conocidos y, aun así, fallar con observaciones nuevas. Por eso reservaremos una parte de los datos para la prueba.

Cuando las filas siguen un orden temporal, no conviene mezclarlas al azar. Utilizaremos el primer 75 % para entrenar y el último 25 % para probar el modelo. iloc permite realizar este corte por posición:

Código
corte = int(len(datos_modelo) * 0.75)

X_entrenamiento = X.iloc[:corte]
X_prueba = X.iloc[corte:]
y_entrenamiento = y.iloc[:corte]
y_prueba = y.iloc[corte:]

print(X_entrenamiento.shape)
print(X_prueba.shape)
Resultado
(12, 3)
(4, 3)
Evitar información futura: las variables predictoras de una fila deben calcularse únicamente con información que ya estaría disponible en ese momento. Si una columna utiliza datos posteriores, el modelo aprenderá con una ventaja que no existiría al realizar una predicción real.

6. Definir el modelo

Utilizaremos DecisionTreeRegressor, un árbol de decisión para valores numéricos. El modelo divide los ejemplos en grupos a partir de las variables predictoras y asigna una predicción a cada grupo.

Su constructor dispone de muchas opciones, pero para este primer ejemplo solo necesitamos dos:

Parámetro Qué controla Valor del ejemplo
max_depthEl número máximo de niveles del árbol. Una profundidad pequeña limita su complejidad.2
random_stateFija la parte aleatoria para obtener el mismo resultado al repetir el código.1
Código
from sklearn.tree import DecisionTreeRegressor

modelo = DecisionTreeRegressor(
    max_depth=2,
    random_state=1,
)

Crear el objeto no lo entrena todavía. En este momento solo hemos elegido el tipo de modelo y guardado su configuración.

7. Entrenar con fit()

El método fit(X, y) recibe las variables predictoras y los resultados conocidos. Durante esta llamada, el modelo aprende los patrones de los datos de entrenamiento.

EntradaContenidoForma
X_entrenamientoVariables predictoras de los ejemplos conocidos.(12, 3)
y_entrenamientoResultado asociado a cada fila.(12,)
Código
modelo.fit(X_entrenamiento, y_entrenamiento)

Después de ejecutar fit(), el objeto modelo conserva lo aprendido y ya puede utilizarse para generar predicciones. No debemos pasarle X_prueba durante el entrenamiento, porque necesitamos reservar esos datos para una evaluación independiente.

8. Predecir con predict()

predict(X) recibe únicamente las variables predictoras. Las columnas deben ser las mismas, estar en el mismo orden y recibir el mismo tipo de preparación que durante el entrenamiento. El método devuelve un array de NumPy con una predicción por fila.

Código
predicciones = modelo.predict(X_prueba)
print(predicciones)
Resultado
[0.0018 0.0018 0.009  0.0018]

Las cuatro predicciones corresponden, en el mismo orden, a las cuatro filas de X_prueba. Obtener un resultado no significa que el modelo sea preciso; todavía debemos compararlo con los valores reales reservados en y_prueba.

9. Evaluar con el error absoluto medio

El error absoluto de una observación es la distancia entre su valor real y la predicción, sin importar cuál de los dos sea mayor:

error absoluto = abs(valor real - predicción)

El error absoluto medio, conocido como MAE por sus siglas en inglés, calcula la media de esos errores. Se interpreta en las mismas unidades que la variable objetivo y siempre es mayor o igual que cero. Cuanto menor sea, más próximas estarán las predicciones a los valores reales.

Código
from sklearn.metrics import mean_absolute_error

mae = mean_absolute_error(y_prueba, predicciones)
print(f"MAE: {mae:.5f}")
Resultado
MAE: 0.00755

Este valor indica que, en las observaciones de prueba, las predicciones se alejan del resultado real una media de 0.00755. No existe un valor de MAE que sea bueno para todos los problemas: debe interpretarse según la escala del objetivo y compararse con otras referencias o modelos evaluados sobre los mismos datos.

11. Qué demuestra este primer modelo

El ejemplo muestra el flujo técnico de scikit-learn, pero un modelo entrenado con dieciséis observaciones no es suficiente para obtener conclusiones fiables. Una predicción es una estimación basada en patrones anteriores, no una certeza.

  • El conjunto de prueba debe permanecer separado del entrenamiento.
  • Las variables predictoras no deben contener información posterior al momento de la predicción.
  • Una métrica calculada sobre datos nuevos es más informativa que el error sobre los datos de entrenamiento.
  • El orden y los nombres de las columnas de X_prueba deben coincidir con los utilizados en fit().
  • Una buena métrica técnica no convierte por sí sola un modelo en una herramienta válida para tomar decisiones.

La selección avanzada de variables, el ajuste de parámetros, la validación temporal con varias ventanas, los pipelines y la comparación exhaustiva de modelos quedan fuera de esta introducción.

Resumen

  • En aprendizaje supervisado, el modelo aprende a relacionar unas variables predictoras con un resultado conocido.
  • La regresión predice valores numéricos y la clasificación predice categorías.
  • X contiene las variables predictoras e y, la variable objetivo.
  • Los datos ordenados temporalmente se separan conservando el pasado para entrenar y el tramo posterior para probar.
  • fit() entrena el modelo y predict() genera estimaciones para nuevas filas.
  • mean_absolute_error() resume la distancia media entre los valores reales y las predicciones.
  • La evaluación debe realizarse con datos que el modelo no haya utilizado durante el entrenamiento.
  • Evitar información futura es esencial para obtener una evaluación válida.
