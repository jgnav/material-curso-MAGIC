1.2. Funciones y obtención de ayuda

En la lección anterior utilizaste funciones como print(), round() y type(). Ahora veremos con más detalle cómo se utilizan, cómo consultar su documentación y cómo crear funciones propias para reutilizar cálculos sin repetir código.

1. Funciones que ya conoces

Una función es un bloque de código preparado para realizar una tarea concreta. Algunas funciones vienen incorporadas en Python; por eso podemos utilizarlas directamente sin definirlas antes.

Para llamar a una función escribimos su nombre seguido de paréntesis. Dentro de los paréntesis colocamos los valores con los que queremos que trabaje. Por ejemplo, round(37.486, 2) llama a round() con el número que queremos redondear y el número de decimales que queremos conservar.

Código
perdida = -37.486
perdida_absoluta = abs(perdida)
perdida_redondeada = round(perdida_absoluta, 2)

print(perdida_redondeada)
Resultado
37.49

En este ejemplo, abs() devuelve el valor absoluto de la pérdida y round() redondea el resultado. Después guardamos cada resultado en una variable, igual que hacíamos con los cálculos aritméticos.

Función incorporada Tarea Ejemplo
print()Muestra información.print("Resultado")
round()Redondea un número.round(5.176, 2)
abs()Calcula el valor absoluto.abs(-25)
min()Devuelve el menor valor.min(48.60, 51.15)
max()Devuelve el mayor valor.max(48.60, 51.15)
type()Consulta el tipo de un valor.type(51.15)

2. Obtener ayuda con help()

Python incluye muchas funciones y no es necesario memorizar todos sus detalles. La función help() permite consultar cómo se utiliza otra función y es una de las herramientas más útiles cuando estamos aprendiendo.

Para consultar la ayuda de round(), escribimos el nombre de la función dentro de help(), pero sin llamarla:

Código
help(round)
Parte del resultado
round(number, ndigits=None)
    Round a number to a given precision in decimal digits.

La primera línea muestra la firma de la función: round(number, ndigits=None). Nos indica que necesita un número y que admite un segundo valor llamado ndigits. El valor None señala que este segundo valor es opcional.

Debajo aparece una descripción breve. La documentación de Python y de muchas bibliotecas suele estar escrita en inglés, pero no hace falta entender cada palabra para obtener información útil: normalmente conviene localizar primero el nombre de la función, sus argumentos y una descripción general.

La ayuda también puede descubrirnos opciones que todavía no conocíamos. Por ejemplo, help(print) muestra un argumento opcional llamado sep, que permite elegir el texto que separa los valores mostrados:

Código
print("SAN", "BBVA", "IBE", sep=" | ")
Resultado
SAN | BBVA | IBE

Al escribir sep=" | " proporcionamos el argumento indicando su nombre. Más adelante utilizaremos esta misma forma de llamada con nuestras propias funciones.

Error habitual: escribe help(round), no help(round(37.486, 2)). En el segundo caso, Python ejecuta primero round() y después muestra la ayuda del número que ha obtenido, no la ayuda de la función.

3. Definir una función propia

Las funciones incorporadas resultan muy útiles, pero también podemos crear funciones adaptadas a nuestros cálculos. Imagina que aplicamos una comisión del 0,1 % a distintas operaciones. En lugar de escribir la misma fórmula cada vez, podemos definir una función:

Código
def calcular_comision(importe):
    comision = importe * 0.001
    return comision

Toda función tiene una cabecera y un cuerpo:

  • La cabecera empieza con def, incluye el nombre de la función y termina con dos puntos (:).
  • importe es el parámetro que recibirá el valor de entrada.
  • Las líneas del cuerpo están sangradas cuatro espacios. Esta indentación indica que pertenecen a la función.
  • return devuelve el resultado al lugar desde el que se llamó a la función.

Al ejecutar esta definición, Python aprende qué debe hacer calcular_comision(), pero todavía no realiza ningún cálculo. Para ejecutar el cuerpo de la función tendremos que llamarla.

4. Llamar y reutilizar una función

Llamar a una función significa ejecutarla. Al escribir calcular_comision(5000), el valor 5000 ocupa temporalmente el lugar del parámetro importe. La función calcula la comisión y devuelve 5.0.

Código
comision_compra = calcular_comision(5000)
comision_venta = calcular_comision(12500)

print(comision_compra)
print(comision_venta)
Resultado
5.0
12.5

La misma función sirve para tantos importes como necesitemos. Si más adelante cambia la fórmula, bastará con modificarla en la definición en lugar de buscar y corregir el cálculo en muchos lugares.

Este es uno de los principales motivos para utilizar funciones: reducen la repetición, hacen que el código sea más fácil de leer y disminuyen las oportunidades de introducir errores.

5. Parámetros y argumentos

Los términos parámetro y argumento están relacionados, pero no significan exactamente lo mismo:

Término Significado Ejemplo
ParámetroNombre que aparece al definir la función.importe
ArgumentoValor concreto que proporcionamos al llamar a la función.5000

Una función puede recibir varios parámetros. Se escriben dentro de los paréntesis y se separan con comas. En la llamada debemos proporcionar un argumento para cada parámetro y respetar el mismo orden.

Código
def calcular_beneficio(precio_compra, precio_venta, cantidad):
    coste = precio_compra * cantidad
    ingreso = precio_venta * cantidad
    beneficio = ingreso - coste
    return beneficio

resultado = calcular_beneficio(48.60, 51.15, 80)
print(round(resultado, 2))
Resultado
204.0

En esta llamada, 48.60 se asigna a precio_compra, 51.15 a precio_venta y 80 a cantidad. Cuando la función termina, el valor devuelto se guarda en resultado.

6. Devolver un resultado con return

return envía un valor fuera de la función. Ese valor puede guardarse en una variable, mostrarse con print() o utilizarse en otro cálculo.

Código
def calcular_valor_final(capital, rentabilidad_pct):
    incremento = capital * rentabilidad_pct / 100
    valor_final = capital + incremento
    return valor_final

capital_despues_operacion = calcular_valor_final(10000, 3.5)
print(capital_despues_operacion)
Resultado
10350.0

Las variables creadas dentro del cuerpo, como incremento y valor_final, son variables locales: solo existen dentro de esa función. Si necesitamos utilizar uno de sus valores fuera, debemos devolverlo con return.

print() y return no hacen lo mismo: print() muestra información en pantalla; return entrega un valor para que el resto del programa pueda reutilizarlo. Una función puede mostrar algo sin devolver ningún valor, pero entonces no podremos guardar su resultado. En ese caso, Python devuelve el valor especial None.

7. Parámetros opcionales

Algunos parámetros pueden tener un valor predeterminado. Esto permite llamar a la función sin proporcionar siempre todos los argumentos. En el siguiente ejemplo, la comisión predeterminada es del 0,1 %:

Código
def calcular_comision(importe, porcentaje=0.001):
    return importe * porcentaje

print(calcular_comision(5000))
print(calcular_comision(5000, 0.002))
print(calcular_comision(5000, porcentaje=0.0025))
Resultado
5.0
10.0
12.5

En la primera llamada no indicamos porcentaje, así que Python utiliza 0.001. En las dos llamadas siguientes sustituimos ese valor. La última utiliza un argumento con nombre, lo que deja claro qué parámetro estamos modificando.

Los parámetros obligatorios deben aparecer antes que los opcionales en la definición. En este caso, importe es obligatorio y porcentaje es opcional.

8. Documentar nuestras funciones

help() también puede utilizarse con las funciones que escribimos. Para que la ayuda explique su propósito, añadimos una docstring: un texto entre comillas triples colocado justo después de la cabecera.

Código
def calcular_rentabilidad(precio_inicial, precio_final):
    """Calcula la rentabilidad porcentual entre dos precios."""
    rentabilidad = (precio_final / precio_inicial - 1) * 100
    return rentabilidad

help(calcular_rentabilidad)
Parte del resultado
calcular_rentabilidad(precio_inicial, precio_final)
    Calcula la rentabilidad porcentual entre dos precios.

La firma indica qué argumentos necesita la función y la docstring explica qué hace. Escribir descripciones breves y claras facilita que otras personas —y nosotros mismos en el futuro— podamos reutilizar el código correctamente.

9. Ejemplo completo: beneficio neto de una operación

Vamos a reunir lo aprendido en una función que calcula el beneficio neto de una compraventa. La función recibe los precios, la cantidad de acciones y una comisión por operación. Esta última tiene un valor predeterminado de 1,50 €.

Código
def calcular_beneficio_neto(precio_compra, precio_venta, cantidad, comision=1.50):
    """Calcula el beneficio después de las comisiones de compra y venta."""
    coste_total = precio_compra * cantidad + comision
    ingreso_total = precio_venta * cantidad - comision
    beneficio_neto = ingreso_total - coste_total
    return beneficio_neto

operacion_1 = calcular_beneficio_neto(48.60, 51.15, 80)
operacion_2 = calcular_beneficio_neto(25.40, 26.10, 100, comision=2.00)

print("Operación 1:", round(operacion_1, 2), "€")
print("Operación 2:", round(operacion_2, 2), "€")
Resultado
Operación 1: 201.0 €
Operación 2: 66.0 €

La primera llamada utiliza la comisión predeterminada. La segunda proporciona una comisión diferente mediante un argumento con nombre. En ambos casos reutilizamos la misma definición y guardamos el valor devuelto antes de mostrarlo.

10. Depuración de errores en funciones

Cuando una llamada no coincide con la definición de una función, Python suele mostrar un TypeError. Por ejemplo, calcular_beneficio() necesita tres argumentos, pero en esta llamada solo proporcionamos dos:

Código con error
calcular_beneficio(48.60, 51.15)
Mensaje de error
TypeError: calcular_beneficio() missing 1 required positional argument: 'cantidad'

La última parte del mensaje señala que falta cantidad. Podemos revisar la definición o ejecutar help(calcular_beneficio) para recordar qué argumentos necesita.

Al definir una función, otros errores frecuentes son olvidar los dos puntos al final de la cabecera o no indentar su cuerpo. En esos casos, Python muestra normalmente SyntaxError o IndentationError. Conviene revisar primero la línea indicada y comprobar la cabecera y sus espacios.

Resumen

  • Una función agrupa código que realiza una tarea concreta.
  • Para llamar a una función escribimos su nombre seguido de paréntesis.
  • help() muestra la firma y la documentación de una función.
  • def inicia la definición y el cuerpo debe estar indentado.
  • Los parámetros aparecen en la definición; los argumentos son los valores utilizados en la llamada.
  • return devuelve un valor para poder reutilizarlo fuera de la función.
  • Un parámetro con valor predeterminado es opcional.
  • Una docstring describe la función y aparece al consultar help().
