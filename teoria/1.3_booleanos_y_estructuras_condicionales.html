1.3. Booleanos y estructuras condicionales

En la lección anterior creaste funciones que realizaban siempre el mismo cálculo. Ahora aprenderás a hacer que el código tome decisiones: comparar valores, combinar condiciones y ejecutar instrucciones diferentes según los datos recibidos.

1. Los valores True y False

Un booleano, cuyo tipo en Python es bool, solo puede tener dos valores: True o False. Estos valores permiten representar respuestas a preguntas de sí o no, como si el mercado está abierto o si una orden se ha ejecutado.

True y False se escriben con la primera letra en mayúscula y sin comillas. Si los escribimos entre comillas, Python los tratará como texto.

Código
mercado_abierto = True
orden_ejecutada = False

print(mercado_abierto)
print(orden_ejecutada)
print(type(mercado_abierto))
Resultado
True
False
<class 'bool'>

Aunque podemos asignar estos valores directamente, lo más habitual es obtenerlos como resultado de una comparación.

2. Comparar valores

Los operadores de comparación responden a preguntas como “¿es este precio mayor que el nivel?” o “¿son iguales estos dos valores?”. El resultado de cualquier comparación es siempre True o False.

Código
precio_actual = 105.20
nivel = 103.00

print(precio_actual > nivel)
print(precio_actual == nivel)
print(precio_actual != nivel)
Resultado
True
False
True
Operador Significado Ejemplo
==Igual aprecio == 100
!=Distinto deprecio != 100
<Menor queprecio < 100
<=Menor o igual queprecio <= 100
>Mayor queprecio > 100
>=Mayor o igual queprecio >= 100
Importante: = asigna un valor a una variable, mientras que == compara dos valores. precio = 100 cambia el valor de precio; precio == 100 pregunta si su valor es 100.

Los tipos también influyen en una comparación. Python considera que el entero 100 y el decimal 100.0 representan el mismo valor numérico, pero el texto "100" es diferente:

Código
print(100.0 == 100)
print("100" == 100)
Resultado
True
False

3. Funciones que devuelven booleanos

Una comparación puede aparecer directamente después de return. De esta forma creamos funciones que responden a una pregunta y devuelven True o False.

Código
def supera_nivel(precio, nivel):
    """Indica si un precio ha alcanzado o superado un nivel."""
    return precio >= nivel

print(supera_nivel(105.20, 103.00))
print(supera_nivel(101.50, 103.00))
Resultado
True
False

No necesitamos escribir return True y return False por separado: la expresión precio >= nivel ya produce uno de esos dos valores.

4. Combinar condiciones con and, or y not

A menudo una decisión depende de varias condiciones. Python permite combinarlas mediante tres operadores lógicos:

Operador Resultado Ejemplo
andEs True cuando todas las condiciones son verdaderas.mercado_abierto and riesgo_aceptable
orEs True cuando al menos una condición es verdadera.senal_compra or senal_venta
notInvierte un booleano: True pasa a False y viceversa.not orden_bloqueada
Código
mercado_abierto = True
riesgo_aceptable = True
orden_bloqueada = False

puede_enviar_orden = mercado_abierto and riesgo_aceptable and not orden_bloqueada
requiere_atencion = (not mercado_abierto) or orden_bloqueada

print(puede_enviar_orden)
print(requiere_atencion)
Resultado
True
False

Cuando una expresión combina varios operadores, los paréntesis ayudan a dejar clara la intención. Python evalúa and antes que or, pero es más seguro escribir explícitamente cómo se agrupan las condiciones que depender de recordar ese orden.

Código
mercado_abierto = True
senal_compra = True
senal_venta = False
riesgo_superado = False

puede_operar = (
    mercado_abierto
    and (senal_compra or senal_venta)
    and not riesgo_superado
)

print(puede_operar)
Resultado
True

5. Ejecutar código con if

Una estructura if ejecuta un bloque de código solamente cuando su condición es True. La línea termina con dos puntos y las instrucciones que dependen de la condición se escriben con cuatro espacios de indentación.

Código
precio_actual = 105.20
nivel = 103.00

if precio_actual > nivel:
    print("El precio ha superado el nivel")

print("Comprobación finalizada")
Resultado
El precio ha superado el nivel
Comprobación finalizada

El primer mensaje pertenece al bloque del if y solo aparece porque la comparación es verdadera. El segundo no está indentado, así que se ejecuta siempre. Si precio_actual > nivel fuese False, Python saltaría el bloque indentado y continuaría con la siguiente instrucción.

6. Elegir entre dos caminos con if-else

else permite indicar qué debe ocurrir cuando la condición del if es falsa. De los dos bloques se ejecutará exactamente uno.

Código
beneficio = -32.50

if beneficio > 0:
    estado = "Operación con beneficio"
else:
    estado = "Operación sin beneficio"

print(estado)
Resultado
Operación sin beneficio

Como beneficio > 0 es False, Python omite el primer bloque y ejecuta el bloque de else. else no lleva condición: representa todos los casos que no cumplieron la condición anterior.

7. Comprobar varias posibilidades con if-elif-else

Cuando necesitamos más de dos caminos, añadimos uno o varios bloques elif, abreviatura de else if. Python comprueba las condiciones de arriba abajo y ejecuta únicamente el primer bloque cuya condición sea True.

Código
variacion_pct = 0.40

if variacion_pct >= 1:
    senal = "Comprar"
elif variacion_pct <= -1:
    senal = "Vender"
else:
    senal = "Mantener"

print(senal)
Resultado
Mantener

La variación no alcanza el 1 % ni cae hasta el −1 %, por lo que las dos primeras condiciones son falsas y se ejecuta else. Tanto elif como else son opcionales, y podemos utilizar tantos bloques elif como necesitemos.

8. Un if-else en una sola línea

Cuando solo queremos elegir entre dos valores, podemos escribir una expresión condicional en una línea. Su estructura es valor_si_verdadero if condicion else valor_si_falso.

Código
beneficio = 125.40
estado = "Con beneficio" if beneficio > 0 else "Sin beneficio"

print(estado)
Resultado
Con beneficio

Python evalúa beneficio > 0. Como la condición es verdadera, asigna "Con beneficio" a estado. Si fuese falsa, asignaría el valor situado después de else.

Esta forma resulta útil para decisiones breves. Si cada rama necesita varias instrucciones o la expresión se vuelve difícil de leer, es preferible utilizar un bloque if-else normal.

9. Ejemplo completo: comprobar límites básicos

Podemos combinar comparaciones, operadores lógicos y varias ramas para comprobar si una operación cumple unos límites. En este ejemplo, el valor de la posición no puede superar el 25 % del capital y la pérdida máxima prevista no puede superar el 2 %.

Código
capital = 10000
valor_posicion = 2000
perdida_maxima = 150
mercado_abierto = True

limite_posicion = capital * 0.25
limite_perdida = capital * 0.02

if not mercado_abierto:
    resultado = "Mercado cerrado"
elif valor_posicion > limite_posicion:
    resultado = "Posición demasiado grande"
elif perdida_maxima > limite_perdida:
    resultado = "Riesgo demasiado alto"
else:
    resultado = "Operación permitida"

print(resultado)
Resultado
Operación permitida

Python comprueba las condiciones de arriba abajo. Como el mercado está abierto y los dos límites se cumplen, llega al bloque else. Si cambiamos los valores iniciales y volvemos a ejecutar el código, el resultado puede proceder de otra rama.

Resumen

  • Los booleanos solo pueden tener los valores True y False.
  • Los operadores ==, !=, <, <=, > y >= comparan valores.
  • and, or y not permiten combinar o invertir condiciones.
  • if ejecuta un bloque cuando su condición es verdadera.
  • else cubre los casos que no cumplen las condiciones anteriores.
  • elif permite comprobar varias posibilidades en orden.
  • Una expresión condicional permite elegir entre dos valores en una sola línea.
  • Los dos puntos y la indentación delimitan el código que pertenece a cada rama.
