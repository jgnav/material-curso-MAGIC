1.5. Bucles

En la lección anterior aprendiste a reunir varios datos en una lista. Ahora veremos cómo recorrer esos datos y ejecutar las mismas instrucciones para cada elemento. Los bucles permiten trabajar con una lista completa sin tener que repetir el código para cada precio, cada sesión o cada activo.

1. Recorrer una lista con for

Un bucle for toma los elementos de una secuencia uno a uno. En el siguiente ejemplo, la variable ticker recibe en cada vuelta un elemento distinto de la lista tickers.

Código
tickers = ["SAN", "IBE", "ITX"]

for ticker in tickers:
    print(ticker)

print("Recorrido terminado")
Resultado
SAN
IBE
ITX
Recorrido terminado

La estructura del bucle contiene cuatro partes:

  • for indica que comienza un bucle.
  • ticker es la variable que utilizará cada elemento durante su vuelta.
  • in tickers señala la secuencia que vamos a recorrer.
  • Los dos puntos y la indentación delimitan las instrucciones que se repiten.

Python ejecuta la línea indentada tres veces: primero con ticker igual a "SAN", después a "IBE" y finalmente a "ITX". Cuando se agotan los elementos, continúa con la primera línea que ya no está indentada. Por eso el último mensaje solo aparece una vez.

2. Combinar un bucle con condiciones

Dentro de un bucle podemos utilizar las estructuras condicionales que ya conocemos. De este modo, cada elemento puede recibir un tratamiento diferente según su valor.

Código
variaciones_pct = [0.8, -0.4, 0.0, 1.2]

for variacion in variaciones_pct:
    if variacion > 0:
        print(variacion, "- Sesión positiva")
    elif variacion < 0:
        print(variacion, "- Sesión negativa")
    else:
        print(variacion, "- Sesión sin cambios")
Resultado
0.8 - Sesión positiva
-0.4 - Sesión negativa
0.0 - Sesión sin cambios
1.2 - Sesión positiva

El bloque del for tiene cuatro espacios de indentación. Los bloques de if, elif y else están dentro del bucle, así que sus instrucciones necesitan un segundo nivel de indentación. Para cada variación se ejecuta solamente una de las tres ramas.

3. Repetir un número determinado de veces con range()

La función range() genera una secuencia de números enteros y se utiliza con frecuencia en los bucles. Al igual que ocurre con el slicing, el valor final no se incluye. Por tanto, range(5) produce los números desde 0 hasta 4.

Código
for numero in range(5):
    print(numero)
Resultado
0
1
2
3
4
Llamada Números generados
range(5)0, 1, 2, 3, 4
range(2, 6)2, 3, 4, 5
range(2, 10, 2)2, 4, 6, 8

La forma range(inicio, fin, paso) permite indicar dónde comienza la secuencia y cuánto avanza en cada vuelta. Si solo queremos recorrer los elementos de una lista, normalmente es más claro escribir for elemento in lista. range() resulta especialmente útil cuando necesitamos trabajar con posiciones.

4. Trabajar con posiciones consecutivas

Para calcular la variación entre dos precios consecutivos necesitamos acceder al precio actual y al anterior. En este caso recorremos los índices desde 1, porque el primer precio no tiene una sesión anterior con la que compararse.

Código
precios_cierre = [100.00, 102.00, 101.00, 104.00]
variaciones_pct = []

for indice in range(1, len(precios_cierre)):
    precio_anterior = precios_cierre[indice - 1]
    precio_actual = precios_cierre[indice]
    variacion = (precio_actual / precio_anterior - 1) * 100
    variaciones_pct.append(round(variacion, 2))

print(variaciones_pct)
Resultado
[2.0, -0.98, 2.97]

range(1, len(precios_cierre)) genera los índices 1, 2 y 3. En cada vuelta, indice señala el precio actual e indice - 1 señala el anterior. Cada resultado redondeado se añade a variaciones_pct mediante append().

5. Obtener la posición y el valor con enumerate()

En ocasiones necesitamos tanto el elemento como su posición. La función enumerate() nos entrega ambos valores en cada vuelta y evita tener que mantener un contador manual.

Código
precios_cierre = [101.20, 102.45, 100.80]

for numero_sesion, precio in enumerate(precios_cierre, start=1):
    print("Sesión", numero_sesion, "-", precio)
Resultado
Sesión 1 - 101.2
Sesión 2 - 102.45
Sesión 3 - 100.8

En cada vuelta, numero_sesion recibe la posición y precio recibe el elemento correspondiente. De forma predeterminada, enumerate() empieza a contar desde 0; con el argumento start=1 hacemos que la numeración mostrada comience en 1.

6. Acumuladores y contadores

Un acumulador es una variable cuyo valor se actualiza en cada vuelta del bucle. Puede utilizarse para sumar cantidades, construir una lista o contar cuántos elementos cumplen una condición.

Código
variaciones_pct = [0.8, -0.4, 0.0, 1.2, -0.7]
sesiones_positivas = 0
sesiones_negativas = 0
sesiones_sin_cambios = 0

for variacion in variaciones_pct:
    if variacion > 0:
        sesiones_positivas += 1
    elif variacion < 0:
        sesiones_negativas += 1
    else:
        sesiones_sin_cambios += 1

print(sesiones_positivas)
print(sesiones_negativas)
print(sesiones_sin_cambios)
Resultado
2
2
1

Los contadores se inicializan antes del bucle. La expresión sesiones_positivas += 1 es una forma abreviada de escribir sesiones_positivas = sesiones_positivas + 1. Cuando termina el recorrido, cada variable contiene el total acumulado en su categoría.

7. Repetir mientras se cumpla una condición con while

Un bucle while no recorre necesariamente una lista. Repite su bloque mientras una condición sea True y se detiene cuando pasa a ser False. Resulta útil cuando no sabemos de antemano cuántas repeticiones serán necesarias.

Código
capital = 1000
objetivo = 1100
rentabilidad_diaria = 0.02
dias = 0

while capital < objetivo:
    capital = capital * (1 + rentabilidad_diaria)
    dias += 1

print(dias)
print(round(capital, 2))
Resultado
5
1104.08

Al principio de cada vuelta, Python comprueba si capital < objetivo. Dentro del bucle actualizamos el capital y aumentamos el número de días. Tras la quinta vuelta, el capital ya no es inferior al objetivo y la ejecución continúa fuera del bloque.

Importante: alguna variable incluida en la condición debe acercar el bucle a su final. Si capital no cambiase dentro del bloque, la condición seguiría siendo verdadera y el bucle se repetiría indefinidamente.

8. Controlar el recorrido con continue y break

Normalmente, un bucle ejecuta todas sus instrucciones en cada vuelta y continúa hasta agotar la secuencia o hasta que la condición de un while sea falsa. Las instrucciones continue y break permiten alterar ese recorrido.

Saltar una vuelta con continue

continue interrumpe la vuelta actual y pasa directamente al siguiente elemento. Las instrucciones situadas después de continue no se ejecutan en esa vuelta.

Código
variaciones_pct = [0.8, 0.0, -0.4, 1.2]

for variacion in variaciones_pct:
    if variacion == 0:
        continue
    print(variacion)

print("Recorrido terminado")
Resultado
0.8
-0.4
1.2
Recorrido terminado

Cuando variacion vale 0.0, Python ejecuta continue y no llega al print() de esa vuelta. El bucle no termina: continúa con -0.4 y después con 1.2.

Terminar el bucle con break

break finaliza el bucle por completo, aunque todavía queden elementos por recorrer. La ejecución continúa en la primera instrucción situada después del bucle.

Código
precios_cierre = [101.20, 102.45, 97.80, 103.10]
nivel_alerta = 100

for precio in precios_cierre:
    if precio < nivel_alerta:
        print("Alerta:", precio)
        break
    print("Precio revisado:", precio)

print("Comprobación finalizada")
Resultado
Precio revisado: 101.2
Precio revisado: 102.45
Alerta: 97.8
Comprobación finalizada

Al encontrar el primer precio inferior a nivel_alerta, el código muestra la alerta y ejecuta break. El precio 103.10 ya no se revisa. El último mensaje sí aparece porque está fuera del bucle.

Instrucción Efecto
continueOmite el resto de la vuelta actual y comienza la siguiente.
breakTermina el bucle y continúa con el código posterior.

9. Crear listas mediante comprensiones

Es muy habitual recorrer una lista para transformar cada elemento y guardar los resultados en otra. Una comprensión de listas permite expresar ese patrón de forma compacta.

Primero veamos la versión con un bucle tradicional:

Código
variaciones_decimales = [0.008, -0.004, 0.012]
variaciones_pct = []

for variacion in variaciones_decimales:
    variaciones_pct.append(variacion * 100)

print(variaciones_pct)
Resultado
[0.8, -0.4, 1.2]

La misma transformación puede escribirse en una línea:

Código
variaciones_decimales = [0.008, -0.004, 0.012]
variaciones_pct = [variacion * 100 for variacion in variaciones_decimales]

print(variaciones_pct)
Resultado
[0.8, -0.4, 1.2]

La estructura general es [expresion for elemento in secuencia]. Python evalúa la expresión de la izquierda para cada elemento de la secuencia y reúne los resultados en una lista nueva. En este ejemplo, la expresión variacion * 100 se aplica a cada valor de variaciones_decimales.

10. Filtrar valores en una comprensión

También podemos añadir una condición al final de la comprensión. Solo se incorporan a la nueva lista los elementos para los que esa condición es True.

Código
activos = [
    ["SAN", 1.4],
    ["IBE", -0.6],
    ["ITX", 0.9],
    ["REP", -1.2]
]

activos_positivos = [
    activo[0]
    for activo in activos
    if activo[1] > 0
]

print(activos_positivos)
Resultado
['SAN', 'ITX']

Cada activo es una de las listas interiores. La condición activo[1] > 0 conserva únicamente los activos con una variación positiva, mientras que la expresión activo[0] selecciona el ticker que se añadirá al resultado.

Las comprensiones suelen escribirse en una línea, pero dividir una expresión algo más larga como esta ayuda a distinguir sus tres partes: qué valor se guarda, qué secuencia se recorre y qué condición se aplica.

11. Bucle tradicional o comprensión de listas

Las dos formas pueden producir el mismo resultado. La elección depende de cuál exprese con mayor claridad lo que queremos hacer.

Forma Cuándo suele resultar más clara
Bucle tradicionalCuando necesitamos varias instrucciones, actualizar distintos acumuladores o tomar decisiones complejas.
Comprensión de listasCuando queremos crear una lista mediante una transformación o un filtro sencillo.

Escribir menos líneas puede ser conveniente, pero no debe dificultar la lectura. Si una comprensión necesita varias condiciones o una expresión difícil de interpretar, un bucle tradicional será normalmente una opción mejor.

12. Ejemplo completo: calcular y filtrar retornos

En este último ejemplo reunimos varias ideas de la lección. Primero recorremos posiciones consecutivas para calcular los retornos de una serie de precios. Después utilizamos comprensiones para separar los retornos positivos y negativos.

Código
precios_cierre = [100.00, 102.00, 101.00, 104.00, 103.00]
retornos_pct = []

for indice in range(1, len(precios_cierre)):
    retorno = (precios_cierre[indice] / precios_cierre[indice - 1] - 1) * 100
    retornos_pct.append(round(retorno, 2))

retornos_positivos = [retorno for retorno in retornos_pct if retorno > 0]
retornos_negativos = [retorno for retorno in retornos_pct if retorno < 0]

print(retornos_pct)
print(retornos_positivos)
print(retornos_negativos)
Resultado
[2.0, -0.98, 2.97, -0.96]
[2.0, 2.97]
[-0.98, -0.96]

El bucle tradicional resulta apropiado para el cálculo porque necesita utilizar dos posiciones y varias operaciones. Una vez creada la lista de retornos, las dos comprensiones expresan de forma directa los filtros que queremos aplicar.

Resumen

  • Un bucle for recorre los elementos de una secuencia uno a uno.
  • Podemos combinar un bucle con condiciones y utilizar varios niveles de indentación.
  • range() genera secuencias de enteros y permite recorrer posiciones.
  • enumerate() proporciona al mismo tiempo la posición y el valor.
  • Los acumuladores se actualizan en cada vuelta para sumar valores, construir listas o contar casos.
  • Un bucle while se repite mientras su condición sea verdadera.
  • continue salta el resto de una vuelta y break termina el bucle.
  • Las comprensiones crean listas nuevas mediante transformaciones y filtros sencillos.
  • Cuando una comprensión dificulta la lectura, es preferible utilizar un bucle tradicional.
