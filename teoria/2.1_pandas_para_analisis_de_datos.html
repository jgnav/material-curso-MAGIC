2.1. Pandas para análisis de datos

En el primer módulo aprendimos a trabajar con los elementos fundamentales de Python. A partir de ahora utilizaremos bibliotecas especializadas. Comenzaremos con Pandas, una biblioteca diseñada para cargar, organizar, limpiar y analizar datos tabulares. Sus objetos y métodos incorporan más posibilidades que los tipos básicos, pero siguen apoyándose en las mismas ideas: variables, listas, diccionarios, condiciones y funciones.

1. Importar Pandas

Como vimos en la lección anterior, antes de utilizar una biblioteca debemos importarla. La convención habitual es asignar a Pandas el alias pd. Encontrarás este alias en la mayoría de cursos, notebooks y ejemplos de documentación.

Código
import pandas as pd

A partir de ese momento, las funciones y objetos de la biblioteca estarán disponibles a través de pd. Por ejemplo, pd.DataFrame() crea una tabla y pd.read_csv() carga una tabla desde un archivo CSV.

2. Los dos objetos principales: Series y DataFrame

Pandas utiliza principalmente dos tipos de objetos. Un DataFrame es una tabla formada por filas y columnas. Cada fila suele representar una observación —por ejemplo, una sesión de mercado— y cada columna contiene una variable, como la fecha, el precio de cierre o el volumen.

Una Series es una secuencia de valores acompañada por un índice. Podemos pensar en ella como una sola columna de un DataFrame. De hecho, al seleccionar una única columna de una tabla normalmente obtenemos una Series.

Objeto Estructura Ejemplo
SeriesUna dimensiónUna columna de precios de cierre
DataFrameDos dimensiones: filas y columnasUn histórico con fecha, apertura, máximo, mínimo, cierre y volumen

Ambos objetos poseen un índice, que identifica las filas. Si no indicamos uno, Pandas crea automáticamente las etiquetas 0, 1, 2 y así sucesivamente. El índice se parece a la numeración de una lista, aunque en Pandas también puede contener fechas o textos.

3. Crear un DataFrame

Podemos crear una tabla a partir de un diccionario. Las claves se convierten en nombres de columnas y cada lista contiene sus valores. Todas las listas deben tener la misma longitud, porque cada posición corresponde a una fila.

Código
import pandas as pd

datos = {
    "Date": ["2026-01-02", "2026-01-05", "2026-01-06",
             "2026-01-07", "2026-01-08", "2026-01-09"],
    "Open": [100.0, 101.5, 102.4, 101.7, 103.6, 104.8],
    "High": [102.0, 103.0, 103.2, 104.0, 105.1, 106.0],
    "Low": [99.5, 100.8, 101.0, 101.4, 103.2, 104.1],
    "Close": [101.5, 102.4, 101.7, 103.6, 104.8, 105.4],
    "Volume": [120000, 135000, None, 150000, 142000, 158000],
}

mercado = pd.DataFrame(datos)
mercado

Pandas muestra None como NaN, la representación habitual de un valor ausente. Además, la columna Volume aparece con decimales porque una columna numérica que contiene NaN necesita un tipo capaz de representarlo.

4. Cargar datos desde un archivo CSV

Crear tablas a mano resulta útil para entender su estructura, pero lo habitual es trabajar con datos almacenados en archivos. Un archivo CSV contiene valores separados por comas y puede leerse con pd.read_csv().

Código
import pandas as pd

mercado = pd.read_csv("historico.csv")

El texto entre comillas indica la ruta del archivo. Si el CSV está en la misma carpeta que el notebook, basta con su nombre. Si se encuentra en otra ubicación, hay que proporcionar la ruta correspondiente. read_csv() ofrece numerosos parámetros opcionales, por lo que podemos consultar help(pd.read_csv) cuando necesitemos controlar el separador, las columnas o la interpretación de los datos.

Cargar un archivo no garantiza que sus datos estén preparados para el análisis. Después de leerlo conviene inspeccionar la tabla, revisar los tipos y buscar valores ausentes antes de realizar cálculos.

5. Primera inspección del DataFrame

Un dataset puede contener miles de filas, por lo que no resulta práctico mostrarlo entero. Pandas proporciona varios métodos y atributos para obtener una primera visión general.

Expresión Información que proporciona
mercado.head()Las cinco primeras filas.
mercado.tail()Las cinco últimas filas.
mercado.shapeUna tupla con el número de filas y columnas.
mercado.info()Columnas, valores no nulos, tipos y memoria aproximada.
mercado.describe()Resumen estadístico de las columnas numéricas.
Código
print(mercado.shape)
mercado.head(3)
Primer resultado
(6, 6)

El resultado indica que la tabla tiene seis filas y seis columnas. Tanto head() como tail() aceptan el número de filas que queremos mostrar. Por su parte, describe() permite detectar rápidamente órdenes de magnitud extraños, aunque no sustituye a una revisión cuidadosa de los datos.

6. Seleccionar columnas

La forma más clara de seleccionar una columna consiste en escribir su nombre entre corchetes. El resultado es una Series. Si colocamos varios nombres dentro de una lista, obtenemos un nuevo DataFrame.

Código
cierres = mercado["Close"]
fecha_y_cierre = mercado[["Date", "Close"]]

print(type(cierres))
print(type(fecha_y_cierre))
Resultado
<class 'pandas.core.series.Series'>
<class 'pandas.core.frame.DataFrame'>

Los dobles corchetes del segundo caso tienen una explicación: los corchetes exteriores realizan la selección y los interiores delimitan la lista de columnas. También existe la escritura mercado.Close, pero mercado["Close"] funciona incluso cuando un nombre contiene espacios o coincide con el nombre de un método, por lo que suele ser la opción más segura.

7. Seleccionar filas con iloc y loc

Pandas ofrece dos selectores principales. iloc trabaja con la posición numérica de las filas y columnas. loc trabaja con sus etiquetas y también permite utilizar condiciones.

Código
# Primera fila por posición
primera_fila = mercado.iloc[0]

# Primeras tres filas y columnas Date y Close
primeros_cierres = mercado.iloc[:3, [0, 4]]

# Valor de Close en la fila cuya etiqueta es 0
primer_cierre = mercado.loc[0, "Close"]

print(primer_cierre)
Resultado
101.5

En ambos selectores se indica primero la fila y después la columna. El *slicing* de iloc funciona como en las listas: incluye el comienzo y excluye el final. Con loc, en cambio, un intervalo de etiquetas incluye también la etiqueta final.

Las condiciones producen una Series de valores booleanos que podemos utilizar dentro de loc. Por ejemplo, podemos seleccionar las sesiones cuyo cierre terminó por encima de la apertura:

Código
sesiones_alcistas = mercado.loc[
    mercado["Close"] > mercado["Open"],
    ["Date", "Open", "Close"],
]

sesiones_alcistas

La expresión no modifica mercado: crea otro DataFrame con las filas y columnas seleccionadas.

8. Convertir una columna de fechas

Al leer un CSV, Pandas puede interpretar una fecha como texto. Para trabajar correctamente con información temporal, conviene convertirla mediante pd.to_datetime().

Código
mercado["Date"] = pd.to_datetime(mercado["Date"])

print(mercado["Date"].dtype)
Resultado
datetime64[ns]

dtype indica cómo almacena Pandas los valores de una columna. Después de la conversión, Date deja de ser texto y pasa a ser una columna temporal. Esto permitirá ordenar, comparar y representar las fechas de forma coherente en operaciones posteriores.

9. Identificar y tratar valores ausentes

Los datos reales pueden contener celdas vacías. Pandas suele representarlas como NaN o NaT, dependiendo del tipo de la columna. isna() marca cada valor ausente con True y sum() cuenta cuántos hay en cada columna.

Código
ausentes_por_columna = mercado.isna().sum()
print(ausentes_por_columna)
Resultado
Date      0
Open      0
High      0
Low       0
Close     0
Volume    1
dtype: int64

Una vez identificado el problema, existen varias opciones. dropna() elimina las filas que contienen valores ausentes. fillna() los sustituye por un valor elegido. Para conservar la tabla original podemos trabajar sobre una copia.

Código
# Opción 1: eliminar las filas incompletas
mercado_sin_ausentes = mercado.dropna()

# Opción 2: sustituir el volumen ausente por la mediana
mercado_limpio = mercado.copy()
volumen_mediano = mercado_limpio["Volume"].median()
mercado_limpio["Volume"] = mercado_limpio["Volume"].fillna(volumen_mediano)
No existe una solución universal para los valores ausentes. Eliminar una fila puede descartar información útil y sustituir un valor introduce una estimación. La elección debe depender del significado de la columna y del análisis que se vaya a realizar.

10. Crear columnas calculadas

Una de las ventajas de Pandas es que las operaciones sobre una Series se aplican a todos sus valores. No necesitamos recorrer manualmente las filas con un bucle para restar dos columnas.

Código
mercado["Rango"] = mercado["High"] - mercado["Low"]
mercado["Variacion"] = mercado["Close"] - mercado["Open"]

mercado[["Date", "Rango", "Variacion"]].round(2)

La resta se realiza fila a fila porque ambas Series comparten el mismo índice. Después asignamos el resultado a un nuevo nombre de columna. Este tipo de operación vectorizada suele ser más claro y eficiente que un bucle escrito a mano.

11. Calcular retornos con pct_change()

El retorno entre dos cierres consecutivos se calcula dividiendo el precio actual por el anterior y restando uno. El método pct_change() realiza ese cálculo a lo largo de una Series.

Código
mercado["Retorno"] = mercado["Close"].pct_change(fill_method=None)

print(mercado["Retorno"].round(4))
Resultado
0       NaN
1    0.0089
2   -0.0068
3    0.0187
4    0.0116
5    0.0057
Name: Retorno, dtype: float64

La primera fila contiene NaN porque no existe un cierre anterior con el que compararla. Los retornos se expresan como proporciones: 0.0089 equivale aproximadamente a 0.89 %. El argumento fill_method=None evita que Pandas sustituya automáticamente posibles precios ausentes antes de calcular el cambio.

12. Calcular una media móvil con rolling()

Una operación de ventana utiliza un grupo móvil de filas. rolling(window=3) crea ventanas de tres observaciones y mean() calcula la media dentro de cada una.

Código
mercado["Media_movil_3"] = (
    mercado["Close"]
    .rolling(window=3)
    .mean()
)

print(mercado["Media_movil_3"].round(2))
Resultado
0       NaN
1       NaN
2    101.87
3    102.57
4    103.37
5    104.60
Name: Media_movil_3, dtype: float64

Las dos primeras filas son NaN porque todavía no existen tres cierres para completar la ventana. En la tercera fila, por ejemplo, el resultado es la media de los cierres de las filas 0, 1 y 2. Aquí utilizamos una ventana pequeña para que el cálculo sea fácil de comprobar.

13. Un flujo básico de análisis

Las operaciones anteriores no suelen aparecer de forma aislada. Un primer análisis con Pandas sigue una secuencia parecida a esta:

Código
import pandas as pd

# 1. Cargar
mercado = pd.read_csv("historico.csv")

# 2. Convertir la fecha e inspeccionar
mercado["Date"] = pd.to_datetime(mercado["Date"])
print(mercado.shape)
print(mercado.isna().sum())

# 3. Crear columnas calculadas
mercado["Retorno"] = mercado["Close"].pct_change(fill_method=None)
mercado["Media_movil_3"] = mercado["Close"].rolling(3).mean()

# 4. Seleccionar el resultado que queremos revisar
resultado = mercado[["Date", "Close", "Retorno", "Media_movil_3"]]
resultado.tail()

Este flujo no es una receta rígida. Su finalidad es adquirir un hábito útil: comprender la estructura y la calidad de los datos antes de calcular resultados. En análisis financiero, un error en una fecha, un precio ausente o una columna mal interpretada puede alterar todos los pasos posteriores.

Resumen

  • Pandas se importa habitualmente mediante import pandas as pd.
  • Una Series representa una secuencia con índice y un DataFrame representa una tabla.
  • pd.DataFrame() crea una tabla y pd.read_csv() carga datos desde un CSV.
  • head(), tail(), shape, info() y describe() ayudan a inspeccionar los datos.
  • Los corchetes seleccionan columnas; iloc selecciona por posición y loc por etiquetas o condiciones.
  • pd.to_datetime() convierte textos en fechas.
  • isna(), dropna() y fillna() permiten identificar y tratar valores ausentes.
  • Las operaciones entre columnas crean resultados fila a fila sin necesidad de escribir un bucle.
  • pct_change() calcula cambios relativos y rolling().mean() permite obtener una media móvil.
