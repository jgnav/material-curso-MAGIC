Aritmética y variables para trading

En esta lección aprenderás a realizar cálculos básicos con Python, guardar resultados en variables y detectar errores frecuentes. Los ejemplos utilizan precios y operaciones financieras sencillas.

Objetivos

  • Mostrar información con print().
  • Utilizar suma, resta, multiplicación, división y potencias.
  • Crear y actualizar variables.
  • Combinar varias variables en un cálculo financiero.
  • Interpretar errores básicos como NameError.

1. Mostrar información con print()

print() permite mostrar texto, números y resultados. Los textos se escriben entre comillas.

Entrada [1]
print("Python listo para analizar mercados")
Salida [1]
Python listo para analizar mercados

2. Operaciones aritméticas

Python puede utilizarse como una calculadora. Estas son las operaciones principales:

Operación Símbolo Ejemplo Resultado
Suma+100 + 5105
Resta-105 - 1005
Multiplicación*25 * 4100
División/10000 / 25040.0
Potencia**1.02 ** 12Crecimiento compuesto

Los paréntesis permiten controlar el orden del cálculo. Las potencias se calculan antes que las multiplicaciones, y las multiplicaciones antes que las sumas.

Entrada [2]
capital_inicial = 10000
rentabilidad_mensual = 0.02
meses = 12

capital_final = capital_inicial * (1 + rentabilidad_mensual) ** meses
print(round(capital_final, 2))
Salida [2]
12682.42
Importante: este cálculo es únicamente un ejemplo matemático. Una rentabilidad real no es constante ni está garantizada.

3. Comentarios

Un comentario explica el propósito del código. Python ignora todo lo que aparece después de # en esa línea.

Entrada [3]
# Calcular el rendimiento simple de una operación
rendimiento = (105 - 100) / 100
print(rendimiento)
Salida [3]
0.05

4. Variables

Una variable asigna un nombre a un valor para poder reutilizarlo. El operador = realiza la asignación; no significa “es igual a” en el sentido de una ecuación matemática.

Entrada [4]
ticker = "ABC"
precio_apertura = 100.0
precio_cierre = 103.5

rentabilidad_pct = (precio_cierre / precio_apertura - 1) * 100
print(ticker, round(rentabilidad_pct, 2))
Salida [4]
ABC 3.5

Los nombres de variables deberían ser cortos y descriptivos. Deben cumplir estas reglas:

  • No pueden contener espacios: usa precio_cierre, no precio cierre.
  • Solo pueden contener letras, números y guiones bajos.
  • No pueden comenzar por un número.
  • Python distingue mayúsculas y minúsculas: precio y Precio son variables distintas.

Actualizar una variable

Asignar un nuevo valor reemplaza el anterior. También puedes calcular el nuevo valor utilizando el valor actual.

Entrada [5]
capital = 10000
capital = capital + 250
print(capital)

capital = capital * 1.01
print(round(capital, 2))
Salida [5]
10250
10352.5

5. Combinar varias variables

Dividir un cálculo largo en variables con nombres claros facilita su lectura y reduce errores. El siguiente ejemplo calcula un tamaño de posición a partir de un riesgo máximo.

Entrada [6]
capital = 10000
riesgo_porcentaje = 0.01
precio_entrada = 100
precio_stop = 98

riesgo_maximo = capital * riesgo_porcentaje
riesgo_por_accion = abs(precio_entrada - precio_stop)
numero_acciones = int(riesgo_maximo / riesgo_por_accion)
valor_posicion = numero_acciones * precio_entrada

print("Riesgo máximo:", riesgo_maximo, "€")
print("Número de acciones:", numero_acciones)
print("Valor de la posición:", valor_posicion, "€")
Salida [6]
Riesgo máximo: 100.0 €
Número de acciones: 50
Valor de la posición: 5000 €
Observa: cambiar capital, riesgo_porcentaje o los precios actualiza todo el cálculo sin tener que reescribir la fórmula completa.

6. Depuración: interpretar un NameError

Python exige que el nombre de una variable coincida exactamente con el utilizado al crearla. Un error tipográfico produce normalmente un NameError.

Entrada con error [7]
precio_entrada = 100
print(precio_entrda)
Salida [7]
NameError: name 'precio_entrda' is not defined

El mensaje indica que precio_entrda no existe. La solución es corregir el nombre:

Entrada corregida [8]
print(precio_entrada)
Salida [8]
100

Resumen

  • print() muestra información.
  • Python respeta el orden de las operaciones.
  • # inicia un comentario.
  • = asigna un valor a una variable.
  • Los nombres descriptivos hacen que los cálculos sean más fáciles de revisar.
  • NameError suele indicar que una variable no existe o está mal escrita.
