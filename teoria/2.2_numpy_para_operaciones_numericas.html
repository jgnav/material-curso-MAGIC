2.2. NumPy para operaciones numéricas

En la lección anterior utilizamos Pandas para organizar datos en tablas y trabajar con columnas identificadas por su nombre. Ahora nos centraremos en NumPy, la biblioteca fundamental para realizar operaciones numéricas eficientes con arrays. Aprenderemos a crear y explorar estos objetos, operar sobre todos sus valores y obtener resultados estadísticos sencillos.

1. Importar NumPy

La convención habitual consiste en importar NumPy mediante el alias np. Es el nombre que encontraremos en la mayoría de notebooks, ejemplos y documentación.

Código
import numpy as np

NumPy significa Numerical Python. Su objeto principal es el ndarray, que normalmente llamaremos simplemente array. Muchas bibliotecas científicas se apoyan en NumPy; Pandas, por ejemplo, utiliza arrays para almacenar buena parte de sus datos numéricos.

2. Crear un array

Podemos crear un array pasando una lista a np.array(). El contenido se parece al de una lista, pero el tipo del objeto es diferente y ofrece operaciones especializadas.

Código
import numpy as np

precios_lista = [101.5, 102.4, 101.7, 103.6, 104.8, 105.4]
precios = np.array(precios_lista)

print(type(precios))
print(precios)
Resultado
<class 'numpy.ndarray'>
[101.5 102.4 101.7 103.6 104.8 105.4]

A diferencia de una lista, un array está pensado para contener valores de un mismo tipo. Si combinamos enteros y decimales, NumPy suele convertir los enteros a decimales para utilizar un tipo común. Esta homogeneidad permite realizar los cálculos de forma eficiente.

np.array() es la forma más directa de crear un array a partir de datos que ya tenemos. NumPy también incluye funciones útiles para generar valores: np.arange() crea una secuencia con un paso determinado, np.linspace() reparte una cantidad de valores entre dos extremos y np.zeros() o np.ones() crean arrays inicializados con ceros o unos.

3. Propiedades de un array

Antes de operar con un array conviene conocer su estructura. Sus propiedades principales se consultan sin paréntesis:

Propiedad Información
shapeTamaño de cada dimensión.
sizeNúmero total de elementos.
dtypeTipo utilizado para almacenar los valores.
ndimNúmero de dimensiones.
Código
print(precios.shape)
print(precios.size)
print(precios.dtype)
print(precios.ndim)
Resultado
(6,)
6
float64
1

La forma (6,) indica que tenemos una única dimensión con seis elementos. La coma permite distinguir esa tupla de un número entre paréntesis. El tipo float64 representa números decimales.

4. Diferencias entre listas y arrays

Las listas y los arrays pueden parecer similares, pero sus operadores no tienen siempre el mismo significado. Al sumar dos listas, Python las concatena. Al sumar un número a un array, NumPy aplica la suma a cada elemento.

Código
print(precios_lista + [1])
print(precios + 1)
Resultado
[101.5, 102.4, 101.7, 103.6, 104.8, 105.4, 1]
[102.5 103.4 102.7 104.6 105.8 106.4]

Este comportamiento se conoce como operación vectorizada. No necesitamos escribir un bucle para aplicar la misma operación a todos los valores. Del mismo modo, precios * 2 multiplica cada elemento por dos, mientras que una lista multiplicada por dos repite su contenido.

Los operadores dependen del tipo de objeto. Cuando una expresión produzca un resultado inesperado, utiliza type(), revisa el dtype y consulta la documentación del objeto.

5. Indexación y slicing

En un array de una dimensión utilizamos índices y slicing de la misma forma que en una lista. El primer elemento ocupa la posición 0 y los índices negativos cuentan desde el final.

Código
print(precios[0])
print(precios[-1])
print(precios[1:4])
Resultado
101.5
105.4
[102.4 101.7 103.6]

El intervalo 1:4 incluye las posiciones 1, 2 y 3, pero excluye la posición 4. Conviene recordar además que muchos slices de NumPy son vistas de los datos originales. Si necesitamos una copia independiente que podamos modificar sin afectar al array inicial, utilizaremos precios[1:4].copy().

6. Arrays de dos dimensiones

Un array también puede tener varias dimensiones. En el siguiente ejemplo tenemos dos filas y tres columnas. NumPy no almacena nombres para ellas, por lo que debemos conocer qué representa cada posición o conservar esa información en otra estructura.

Código
retornos_activos = np.array([
    [0.010, 0.004, -0.002],
    [-0.005, 0.008, 0.003],
])

print(retornos_activos.shape)
print(retornos_activos[1, 2])
print(retornos_activos[:, 0])
Resultado
(2, 3)
0.003
[ 0.01  -0.005]

La forma (2, 3) indica dos filas y tres columnas. La expresión [1, 2] selecciona la segunda fila y la tercera columna. En [:, 0], los dos puntos significan «todas las filas» y el 0 selecciona la primera columna.

También podemos reorganizar los valores con reshape(). Por ejemplo, np.arange(6).reshape(2, 3) crea los números del 0 al 5 y los distribuye en dos filas y tres columnas. La nueva forma debe contener el mismo número total de elementos que el array original.

7. Aritmética con arrays

Las operaciones aritméticas pueden combinar un array con un único número o con otro array compatible. La suma, la resta, la multiplicación, la división y la potencia se aplican elemento a elemento, sin necesidad de escribir un bucle. Los operadores // y % también funcionan con arrays y calculan, respectivamente, la división entera y el resto de cada posición.

Código
a = np.array([10, 20, 30])
b = np.array([2, 4, 5])

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a ** 2)
Resultado
[12 24 35]
[ 8 16 25]
[ 20  80 150]
[5. 5. 6.]
[100 400 900]

NumPy empareja los valores que ocupan la misma posición. Por ejemplo, el primer elemento de a * b es 10 * 2. Si escribimos a + 1 o a / 10, el mismo número se aplica a todos los elementos del array. NumPy también proporciona funciones como np.add(), np.subtract(), np.multiply() y np.divide(), equivalentes a los operadores anteriores.

Otras funciones matemáticas habituales, como np.sqrt(), np.exp() y np.log(), siguen la misma idea: reciben un array y calculan la raíz cuadrada, la exponencial o el logaritmo de cada elemento. Si las formas de dos arrays no son compatibles, la operación produce un error o aplica unas reglas de ajuste denominadas broadcasting. En esta introducción utilizaremos arrays con la misma forma o combinaremos un array con un único número.

8. Aritmética en dos dimensiones

Las mismas reglas se aplican a los arrays de dos dimensiones. Los operadores +, -, *, / y ** continúan actuando elemento a elemento. Además, podemos multiplicar todos los valores por un escalar o transponer el array con .T, que intercambia sus filas y columnas.

Código
matriz_a = np.array([
    [1, 2],
    [3, 4],
])

matriz_b = np.array([
    [5, 6],
    [7, 8],
])

print(matriz_a + matriz_b)
print(matriz_a * 2)
print(matriz_a * matriz_b)
print(matriz_a @ matriz_b)
print(matriz_a.T)
Resultado
[[ 6  8]
 [10 12]]
[[2 4]
 [6 8]]
[[ 5 12]
 [21 32]]
[[19 22]
 [43 50]]
[[1 3]
 [2 4]]

Los tres primeros cálculos siguen siendo operaciones elemento a elemento. La expresión matriz_a * matriz_b, por ejemplo, multiplica 1 * 5, 2 * 6 y así sucesivamente. El operador @ tiene un significado distinto: realiza una multiplicación matricial. Para obtener su primer resultado, combina la primera fila de matriz_a con la primera columna de matriz_b: 1 * 5 + 2 * 7 = 19.

La multiplicación matricial solo es posible cuando el número de columnas de la primera matriz coincide con el número de filas de la segunda. Una matriz con forma (2, 3) puede multiplicarse por otra con forma (3, 4), y el resultado tendrá forma (2, 4). np.matmul(matriz_a, matriz_b) realiza la misma operación que matriz_a @ matriz_b. Cuando @ se utiliza con dos arrays de una dimensión, calcula su producto escalar.

9. Combinar slices en un cálculo

Podemos combinar dos slices para operar con elementos consecutivos. precios[1:] contiene todos los valores salvo el primero y precios[:-1] contiene todos salvo el último. Ambos tienen cinco elementos y quedan alineados posición a posición.

Código
retornos = precios[1:] / precios[:-1] - 1

print(retornos.round(4))
Resultado
[ 0.0089 -0.0068  0.0187  0.0116  0.0057]

El array resultante tiene un elemento menos que el original, porque no existe un valor anterior para la primera posición. La expresión divide cada elemento por el anterior y resta uno. Es la misma operación relativa que realiza pct_change() en Pandas, pero aquí la construimos explícitamente mediante NumPy.

10. Comparaciones vectorizadas y filtros

Una comparación aplicada a un array produce otro array de valores booleanos. Esa máscara puede utilizarse para seleccionar únicamente los elementos que cumplen la condición.

Código
es_positivo = retornos > 0
retornos_positivos = retornos[es_positivo]

print(es_positivo)
print(retornos_positivos.round(4))
Resultado
[ True False  True  True  True]
[0.0089 0.0187 0.0116 0.0057]

La máscara y el array original deben tener la misma longitud. Para combinar varias condiciones sobre arrays utilizamos & para «y» y | para «o», colocando cada comparación entre paréntesis. Por ejemplo, retornos[(retornos > 0) & (retornos < 0.01)] selecciona los elementos positivos inferiores a 0.01.

11. Agregaciones y desviación estándar

NumPy incluye funciones para resumir todos los valores de un array. Entre las más habituales se encuentran mean(), sum(), min(), max() y std().

Código
retorno_medio = np.mean(retornos)
sesiones_positivas = np.sum(retornos > 0)
retorno_minimo = np.min(retornos)
retorno_maximo = np.max(retornos)
volatilidad_diaria = np.std(retornos)

print(round(float(retorno_medio), 4))
print(int(sesiones_positivas))
print(round(float(retorno_minimo), 4))
print(round(float(retorno_maximo), 4))
print(round(float(volatilidad_diaria), 4))
Resultado
0.0076
4
-0.0068
0.0187
0.0084

Los valores booleanos se comportan como 1 y 0 al sumarlos, por eso np.sum(retornos > 0) cuenta cuántos elementos cumplen la comparación. np.std() calcula la desviación estándar, una medida de cuánto se separan los valores respecto a su media.

En un array de dos dimensiones, el argumento axis permite elegir la dirección del cálculo: axis=0 obtiene un resultado por cada columna y axis=1 obtiene uno por cada fila. Por ejemplo, np.mean(retornos_activos, axis=0) calcula la media de cada una de sus tres columnas.

El siguiente ejemplo muestra cómo reutilizar un resultado, llamar a np.sqrt() y combinar ambas cantidades mediante una multiplicación. El número 252 es simplemente uno de los datos de entrada elegidos para el ejemplo:

Código
volatilidad_anual = volatilidad_diaria * np.sqrt(252)

print(f"Volatilidad anual: {volatilidad_anual:.2%}")
Resultado
Volatilidad anual: 13.32%

Desde el punto de vista de Python, lo importante es observar que el resultado de una función puede intervenir directamente en otra expresión y que :.2% presenta un decimal con formato porcentual. La interpretación especializada de la variable pertenece al contexto del ejemplo y no es necesaria para comprender el código.

12. Elegir valores con np.where()

np.where() permite escoger entre dos valores según una condición. Recibe tres argumentos: la condición, el valor utilizado cuando se cumple y el valor utilizado cuando no se cumple.

Código
clasificacion = np.where(
    retornos > 0,
    "Positivo",
    "Negativo",
)

print(clasificacion)
Resultado
['Positivo' 'Negativo' 'Positivo' 'Positivo' 'Positivo']

np.where() no elimina elementos: devuelve un resultado para cada posición. Si queremos filtrar y reducir la longitud del array, utilizamos una máscara como hicimos en el apartado anterior.

13. Valores ausentes con NaN

NumPy representa muchos valores numéricos ausentes mediante np.nan. NaN significa Not a Number, pero no equivale a cero. La mayoría de operaciones normales propagan el valor ausente.

Código
retornos_incompletos = np.array([0.0089, np.nan, -0.0068, 0.0187])

es_ausente = np.isnan(retornos_incompletos)
retornos_validos = retornos_incompletos[~es_ausente]

print(es_ausente)
print(np.sum(es_ausente))
print(np.mean(retornos_incompletos))
print(round(float(np.nanmean(retornos_incompletos)), 4))
print(retornos_validos)
Resultado
[False  True False False]
1
nan
0.0069
[ 0.0089 -0.0068  0.0187]

np.isnan() genera una máscara que identifica los valores ausentes. El operador ~ invierte esa máscara y permite seleccionar los valores válidos. Funciones como np.nanmean(), np.nansum() o np.nanstd() ignoran los NaN, pero debemos utilizarlas solo cuando tenga sentido excluir esos datos del cálculo.

14. Trabajar con Pandas y NumPy

Pandas y NumPy no son alternativas excluyentes. Pandas resulta cómodo para conservar etiquetas, fechas y columnas; NumPy proporciona herramientas numéricas sobre los valores. El método to_numpy() convierte una Series o un DataFrame en un array.

Código
import pandas as pd
import numpy as np

serie_cierres = pd.Series(
    [101.5, 102.4, 101.7, 103.6],
    name="Close",
)

array_cierres = serie_cierres.to_numpy()

print(type(serie_cierres))
print(type(array_cierres))
Resultado
<class 'pandas.core.series.Series'>
<class 'numpy.ndarray'>

Al convertir una Series, el array conserva sus valores, pero no el nombre ni las etiquetas del índice. Por eso suele ser conveniente mantener los datos originales en Pandas y utilizar NumPy cuando necesitamos realizar cálculos numéricos concretos.

15. Un flujo numérico completo

Podemos reunir las operaciones principales de la lección en un único flujo de transformación y resumen de un array:

Código
import numpy as np

precios = np.array([101.5, 102.4, 101.7, 103.6, 104.8, 105.4])
retornos = precios[1:] / precios[:-1] - 1

resumen = {
    "sesiones_analizadas": len(retornos),
    "sesiones_positivas": int(np.sum(retornos > 0)),
    "retorno_medio": round(float(np.mean(retornos)), 4),
    "volatilidad_anual": round(
        float(np.std(retornos) * np.sqrt(252)),
        4,
    ),
}

print(resumen)
Resultado
{'sesiones_analizadas': 5, 'sesiones_positivas': 4, 'retorno_medio': 0.0076, 'volatilidad_anual': 0.1332}

El flujo crea un array, calcula cambios relativos entre elementos consecutivos y obtiene varias medidas sin escribir un bucle. El siguiente paso será aprender a representar visualmente este tipo de resultados.

Resumen

  • NumPy se importa habitualmente mediante import numpy as np.
  • np.array() crea arrays a partir de otros datos; np.arange(), np.linspace(), np.zeros() y np.ones() permiten generarlos directamente.
  • shape, size, dtype y ndim describen la estructura de un array.
  • Los arrays admiten indexación y slicing en una o varias dimensiones.
  • Los operadores +, -, *, / y ** actúan elemento a elemento sin necesidad de escribir bucles.
  • * multiplica elemento a elemento; @ y np.matmul() realizan una multiplicación matricial.
  • El atributo .T intercambia las filas y las columnas de un array de dos dimensiones.
  • Las comparaciones producen máscaras booleanas que permiten filtrar valores.
  • mean(), sum(), min(), max() y std() resumen los datos.
  • np.where() elige valores según una condición.
  • np.isnan() identifica valores ausentes y las funciones que comienzan por nan pueden ignorarlos en los cálculos.
  • to_numpy() permite extraer los valores de un objeto de Pandas como array.
