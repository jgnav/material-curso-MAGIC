1.6. Strings y diccionarios

Ya sabemos organizar datos en listas y recorrerlos mediante bucles. En esta lección trabajaremos con dos tipos fundamentales de Python: los strings, que permiten almacenar y transformar texto, y los diccionarios, que relacionan cada dato con una clave descriptiva.

1. Crear strings

Un string, o cadena de texto, es un valor de tipo str. Se puede escribir entre comillas dobles o simples; ambas formas son equivalentes. Elegir una u otra resulta útil cuando el propio texto contiene comillas.

Código
ticker = "SAN"
estado = 'Orden ejecutada'
mensaje = "El ticker 'SAN' está disponible"

print(ticker)
print(estado)
print(mensaje)
print(type(ticker))
Resultado
SAN
Orden ejecutada
El ticker 'SAN' está disponible
<class 'str'>

La secuencia \n representa un salto de línea dentro de un string. También podemos utilizar comillas triples para escribir textos de varias líneas, como ya hicimos en las docstrings de nuestras funciones.

Código
informe = "Ticker: SAN\nPrecio: 4.58"

print(informe)
Resultado
Ticker: SAN
Precio: 4.58

2. Los strings también son secuencias

Un string es una secuencia de caracteres. Por eso admite varias operaciones que ya conocemos de las listas: índices positivos y negativos, slicing, len() y recorridos con for.

Código
codigo = "SAN.MC"

print(codigo[0])
print(codigo[:3])
print(codigo[-2:])
print(len(codigo))
Resultado
S
SAN
MC
6

El índice 0 devuelve el primer carácter, [:3] selecciona los tres primeros y [-2:] los dos últimos. El punto también es un carácter, de modo que len("SAN.MC") devuelve 6.

Código
ticker = "SAN"

for caracter in ticker:
    print(caracter)
Resultado
S
A
N

3. Los strings son inmutables

A diferencia de las listas, los strings son inmutables: no podemos sustituir directamente uno de sus caracteres ni añadir otro mediante append(). Los métodos de texto crean y devuelven un string nuevo; el original no cambia.

Código
codigo = "SAN.MC"
ticker = codigo.replace(".MC", "")

print(codigo)
print(ticker)
Resultado
SAN.MC
SAN

replace() devuelve el texto sin ".MC", que guardamos en una variable distinta. Al mostrar codigo, comprobamos que conserva su valor inicial.

4. Limpiar y normalizar texto

Los datos de texto pueden contener espacios innecesarios o utilizar mayúsculas y minúsculas de forma irregular. Los métodos strip(), upper() y lower() permiten normalizarlos.

Código
ticker_usuario = "  san.mc  "
texto_estado = "  MERCADO ABIERTO  "

ticker_limpio = ticker_usuario.strip().upper()
estado_normalizado = texto_estado.strip().lower()

print(ticker_limpio)
print(estado_normalizado)
Resultado
SAN.MC
mercado abierto
Método Qué devuelve
texto.strip()El texto sin espacios al principio ni al final.
texto.upper()Una copia convertida a mayúsculas.
texto.lower()Una copia convertida a minúsculas.

Podemos encadenar métodos porque cada uno devuelve un nuevo string. Python evalúa la expresión de izquierda a derecha: primero elimina los espacios y después cambia las letras.

5. Buscar y sustituir dentro de un string

Otros métodos permiten comprobar cómo empieza o termina un texto y sustituir una parte por otra. startswith() y endswith() devuelven booleanos, por lo que pueden utilizarse directamente en una condición.

Código
codigo = "SAN.MC"

print(codigo.startswith("SAN"))
print(codigo.endswith(".MC"))
print(codigo.replace(".MC", ""))
Resultado
True
True
SAN

6. Pasar de strings a listas con split() y join()

split() divide un string y devuelve una lista de fragmentos. Si no indicamos ningún argumento, separa por espacios; también podemos especificar otro separador, como una coma.

join() realiza la operación contraria: une una lista de strings y coloca entre ellos el separador sobre el que llamamos al método.

Código
registro = "SAN,4.58,25"
campos = registro.split(",")
resumen = " | ".join(campos)

print(campos)
print(resumen)
Resultado
['SAN', '4.58', '25']
SAN | 4.58 | 25

Los tres elementos de campos siguen siendo strings, aunque algunos contengan dígitos. Si necesitásemos realizar cálculos con ellos, tendríamos que convertirlos al tipo numérico correspondiente con int() o float().

7. Construir mensajes con f-strings

Las f-strings permiten insertar variables y expresiones dentro de un texto. Se escribe la letra f antes de las comillas y se colocan entre llaves los valores que queremos incorporar.

Código
ticker = "SAN"
precio = 4.58
retorno = 0.0137

mensaje = f"{ticker}: {precio:.2f} € | retorno: {retorno:.2%}"

print(mensaje)
Resultado
SAN: 4.58 € | retorno: 1.37%

{ticker} inserta el texto sin cambios. El formato :.2f muestra un número decimal con dos cifras y :.2% convierte el valor decimal a porcentaje y también utiliza dos cifras decimales. Las f-strings se ocupan de convertir los valores a texto al construir el mensaje.

8. Crear un diccionario

Un diccionario relaciona claves con valores. Se escribe entre llaves, { }; cada pareja utiliza dos puntos para separar su clave de su valor, y las parejas se separan mediante comas.

Código
precios = {
    "SAN": 4.58,
    "IBE": 12.40,
    "ITX": 47.20
}

print(precios)
print(type(precios))
Resultado
{'SAN': 4.58, 'IBE': 12.4, 'ITX': 47.2}
<class 'dict'>

En este diccionario, los tickers son las claves y los precios son sus valores. Cada clave debe ser única: no tendría sentido mantener dos valores distintos asociados simultáneamente a la misma clave. Los valores, en cambio, pueden repetirse y pueden ser de cualquier tipo.

9. Acceder a los valores mediante claves

Para recuperar un valor escribimos la clave entre corchetes. Los diccionarios no se consultan mediante posiciones numéricas como las listas, sino mediante las claves que hemos definido.

Código
precios = {"SAN": 4.58, "IBE": 12.40, "ITX": 47.20}

print(precios["SAN"])
print("IBE" in precios)
print(precios.get("BBVA", "No disponible"))
Resultado
4.58
True
No disponible

El operador in comprueba si una clave existe en el diccionario. El método get() también busca una clave, pero permite indicar un valor alternativo para cuando no esté presente. En el ejemplo evita que la consulta de "BBVA" interrumpa el programa y devuelve "No disponible".

10. Añadir y modificar elementos

La misma sintaxis de corchetes sirve para añadir una pareja nueva o actualizar el valor de una clave existente. Los diccionarios, al igual que las listas, son mutables.

Código
precios = {"SAN": 4.58, "IBE": 12.40}

precios["SAN"] = 4.62
precios["REP"] = 13.85

print(precios)
Resultado
{'SAN': 4.62, 'IBE': 12.4, 'REP': 13.85}

Como "SAN" ya era una clave, su precio se actualiza. "REP" no existía, por lo que se incorpora como una nueva pareja.

11. Claves, valores y parejas

Los métodos keys(), values() e items() permiten acceder a las distintas partes de un diccionario.

Método Contenido
diccionario.keys()Todas las claves.
diccionario.values()Todos los valores.
diccionario.items()Todas las parejas de clave y valor.
Código
precios = {"SAN": 4.58, "IBE": 12.40, "ITX": 47.20}

tickers = list(precios.keys())
valores = list(precios.values())

print(tickers)
print(valores)

for ticker, precio in precios.items():
    print(ticker, "->", precio)
Resultado
['SAN', 'IBE', 'ITX']
[4.58, 12.4, 47.2]
SAN -> 4.58
IBE -> 12.4
ITX -> 47.2

keys() y values() devuelven vistas del diccionario; en el ejemplo las convertimos con list() para mostrarlas como listas conocidas. items() resulta especialmente útil en un bucle, ya que permite recibir la clave y su valor en dos variables.

Si escribimos simplemente for ticker in precios, Python también recorre las claves. Utilizar items() deja más claro que necesitamos trabajar con las dos partes.

12. Ejemplo completo: representar una cartera

Los valores de un diccionario pueden ser otros diccionarios. Esta estructura permite agrupar varios datos de cada activo bajo una clave principal: el ticker.

Código
cartera = {
    "SAN": {"cantidad": 25, "precio_compra": 4.58},
    "IBE": {"cantidad": 10, "precio_compra": 12.40}
}

print(cartera["SAN"]["cantidad"])

for ticker, datos in cartera.items():
    valor = datos["cantidad"] * datos["precio_compra"]
    print(f"{ticker}: {datos['cantidad']} acciones, valor {valor:.2f} €")
Resultado
25
SAN: 25 acciones, valor 114.50 €
IBE: 10 acciones, valor 124.00 €

cartera["SAN"] selecciona el diccionario interior del activo y el segundo par de corchetes elige uno de sus datos. En el bucle recorremos cada ticker junto con su diccionario, calculamos el valor de la posición y construimos un mensaje mediante una f-string.

Resumen

  • Los strings son secuencias de caracteres y su tipo en Python es str.
  • Podemos utilizar índices, slicing, len() y bucles sobre un string.
  • Los strings son inmutables: sus métodos devuelven textos nuevos.
  • strip(), upper(), lower() y replace() permiten limpiar y transformar texto.
  • split() divide un string en una lista y join() une una lista de strings.
  • Las f-strings insertan y formatean valores dentro de un mensaje.
  • Los diccionarios relacionan claves únicas con valores.
  • Podemos consultar, añadir y modificar valores mediante sus claves.
  • keys(), values() e items() permiten recorrer las partes de un diccionario.
  • Los diccionarios pueden contener otros diccionarios para representar datos con varios niveles.
