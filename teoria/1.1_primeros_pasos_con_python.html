1.1. Primeros pasos con Python

En esta lección verás varios ejemplos de código Python y el resultado de ejecutarlos. Empezaremos mostrando mensajes y realizando cálculos sencillos. Después aprenderás a guardar valores en variables y a trabajar con distintos tipos de datos.

1. Mostrar un mensaje con print()

Una de las tareas más sencillas que podemos pedirle a un ordenador es que muestre un mensaje. En Python se hace escribiendo print() y colocando el mensaje entre los paréntesis y entre comillas.

Código
print("Hola, mundo")
Resultado
Hola, mundo

El bloque Código contiene la instrucción que hemos escrito y el bloque Resultado muestra la respuesta de Python. Como puedes ver, se ha mostrado exactamente el mensaje que estaba dentro de los paréntesis.

print() es una función incorporada en Python. Estudiaremos las funciones con más detalle en la siguiente lección; por ahora, basta con saber que aquello que colocamos dentro de los paréntesis es lo que queremos mostrar.

Las comillas indican que Hola, mundo es texto. Podemos utilizar comillas dobles (") o simples ('), siempre que abramos y cerremos con el mismo tipo.

Código
print("Precio de cierre")
print('Mercado abierto')
Resultado
Precio de cierre
Mercado abierto

Podemos utilizar print() tantas veces como necesitemos. Cada llamada muestra su resultado en una línea nueva. Más adelante combinaremos texto y resultados numéricos para presentar cálculos de forma clara.

2. Operaciones aritméticas

Además de mostrar mensajes, Python puede utilizarse como una calculadora. Si escribimos una operación dentro de print(), Python la calcula primero y después muestra el resultado.

En el siguiente ejemplo, la primera línea suma 1 y 2. La segunda resta 5 a 9. Esta vez no utilizamos comillas, porque queremos que Python interprete los números y realice las operaciones.

Código
print(1 + 2)
print(9 - 5)
Resultado
3
4

Observa la diferencia: print(1 + 2) muestra 3, pero print("1 + 2") muestra el texto 1 + 2. Cuando una expresión está entre comillas, Python la trata como texto y no la calcula.

Python admite las operaciones aritméticas habituales. Algunos símbolos coinciden con los que usamos en matemáticas y otros, como * para multiplicar o ** para elevar a una potencia, son propios de la escritura de código.

Operación Operador Ejemplo Resultado
Suma+1 + 23
Resta-5 - 41
Multiplicación*2 * 48
División/6 / 32.0
Potencia**3 ** 29

El resultado de una división se muestra normalmente con una parte decimal. Por eso 6 / 3 produce 2.0 en lugar de 2. La diferencia entre estos dos tipos de número se explicará un poco más adelante.

En cálculos más largos, los paréntesis permiten controlar el orden de las operaciones. Python calcula primero el contenido de los paréntesis, después las potencias, las multiplicaciones y divisiones y, por último, las sumas y restas.

Código
print(100 + 5 * 2)
print((100 + 5) * 2)
Resultado
110
210

En la primera expresión, Python multiplica 5 * 2 antes de sumar 100. En la segunda, los paréntesis obligan a calcular primero 100 + 5. Por eso obtenemos dos resultados diferentes aunque aparezcan los mismos números y operadores.

3. Comentarios

Los comentarios sirven para explicar lo que hace el código. Ayudan a otras personas a entenderlo y también nos recuerdan qué pretendíamos hacer cuando volvemos a leerlo más adelante.

Un comentario comienza con #. Python ignora todo lo que aparece después de ese símbolo en la misma línea.

Código
# Calcular el beneficio antes de comisiones
print((105 - 100) * 10)
Resultado
50

El comentario no aparece en el resultado porque Python lo ignora por completo. Si eliminásemos el símbolo #, Python intentaría interpretar el texto como código y mostraría un error. Python tiene reglas estrictas: cualquier texto que no forme parte del código debe estar entre comillas o marcado como comentario.

4. Variables

Hasta ahora hemos calculado valores y los hemos mostrado, pero no los hemos guardado. Una vez mostrado el resultado, no tenemos un nombre con el que recuperarlo para otro cálculo.

Para conservar un dato y poder utilizarlo más tarde necesitamos una variable. Una variable asocia un nombre con un valor. Ese nombre nos permite consultar el valor, incluirlo en operaciones y cambiarlo cuando sea necesario.

Crear una variable

En el ejemplo siguiente creamos una variable llamada precio_compra y le asignamos el valor 102.50. Después mostramos el valor guardado.

Código
# Crear una variable y asignarle un valor
precio_compra = 102.50

# Mostrar el valor guardado
print(precio_compra)
Resultado
102.5

El signo = asigna a la variable de la izquierda el valor situado a la derecha. En programación, esta instrucción se lee como «precio_compra recibe el valor 102.50».

Cuando escribimos print(precio_compra), no ponemos el nombre entre comillas. Queremos que Python busque la variable y muestre el valor que contiene. Si escribiésemos print("precio_compra"), mostraría solamente ese texto.

Los nombres de variables deberían ser breves y descriptivos. Además, deben cumplir estas reglas:

  • No pueden contener espacios: usa precio_compra, no precio compra.
  • Solo pueden contener letras, números y guiones bajos.
  • No pueden comenzar por un número.
  • Python distingue mayúsculas y minúsculas: precio y Precio son variables diferentes.

Elegir buenos nombres puede resultar poco natural al principio. Es normal: se aprende viendo código y practicando. Lo importante es que el nombre permita recordar qué representa el valor.

Cambiar el valor de una variable

Podemos sustituir el valor de una variable mediante una nueva asignación. También podemos utilizar su valor actual para calcular el nuevo.

Código
capital = 10000
print(capital)

# Añadir 250 al valor actual
capital = capital + 250
print(capital)
Resultado
10000
10250

Primero, capital recibe el valor 10000. Después, la expresión situada a la derecha utiliza ese valor y le suma 250. El resultado, 10250, vuelve a guardarse en la misma variable y sustituye al valor anterior.

5. Utilizar varias variables

Los cálculos reales suelen depender de varios datos. Es habitual guardar cada entrada en una variable y utilizar después esas variables en la fórmula. Los nombres nos ayudan a entender qué representa cada dato y facilitan la corrección de errores.

En el siguiente ejemplo calculamos el capital necesario para comprar 12 acciones. El coste no es solo el precio de las acciones: también debemos sumar la comisión de compra.

Código
precio_compra = 102.50
numero_acciones = 12
comision_compra = 2.50

capital_invertido = precio_compra * numero_acciones + comision_compra
print(capital_invertido)
Resultado
1232.5

El cálculo también podría escribirse como 102.50 * 12 + 2.50, pero sería más difícil saber qué significa cada número. Con las variables podemos leer la fórmula casi como una frase: precio de compra por número de acciones, más comisión.

Las variables son especialmente útiles cuando los datos pueden cambiar. Si cambia el precio, el número de acciones o la comisión, basta con actualizar la variable correspondiente y volver a ejecutar el mismo cálculo.

6. Tipos de datos

Cada variable tiene un valor y cada valor pertenece a un tipo de dato. El tipo determina qué operaciones podemos realizar. Por ejemplo, tiene sentido dividir dos números, pero no dividir dos textos.

Ya hemos visto números sin decimales, números con decimales y mensajes entre comillas. Python los distingue aunque todos puedan mostrarse con print(). Conocer su tipo nos ayudará a evitar operaciones incompatibles.

Números enteros: int

Los enteros son números sin parte decimal. Pueden ser positivos, negativos o cero. La función type() permite consultar el tipo de una variable.

Código
numero_acciones = 12
print(numero_acciones)
print(type(numero_acciones))
Resultado
12
<class 'int'>

La salida <class 'int'> indica que numero_acciones contiene un entero. El nombre int procede de integer, «entero» en inglés.

Números decimales: float

Los floats son números con parte decimal. Python utiliza un punto, no una coma, como separador decimal. Incluso 1.0 es un float, aunque su parte decimal sea cero.

Código
precio = 102.50
print(precio)
print(type(precio))
Resultado
102.5
<class 'float'>

La salida <class 'float'> confirma que precio es un número decimal. Este es el tipo que encontraremos con frecuencia al trabajar con precios, retornos o comisiones.

Los cálculos con decimales pueden producir más cifras de las que queremos mostrar. La función round() permite redondear un número a la cantidad de decimales indicada. El primer valor es el número y el segundo indica cuántos decimales queremos conservar.

Código
rentabilidad = 4.7545638
rentabilidad_redondeada = round(rentabilidad, 2)
print(rentabilidad_redondeada)
Resultado
4.75

En este caso, round(rentabilidad, 2) conserva dos decimales. Guardamos el resultado en otra variable para poder utilizar tanto el valor original como el redondeado.

Booleanos: bool

Un booleano solo puede tener dos valores: True o False. Se utilizan para representar si algo es verdadero o falso. Los escribimos con la primera letra en mayúscula y sin comillas.

Código
mercado_abierto = True
print(mercado_abierto)
print(type(mercado_abierto))
Resultado
True
<class 'bool'>

En una lección posterior utilizaremos booleanos para comprobar condiciones, por ejemplo si una operación tiene beneficio o si un precio ha superado determinado nivel.

Cadenas de texto: str

Una cadena de texto, o string, es una secuencia de caracteres escrita entre comillas. Puede contener letras, espacios, signos o cifras.

Código
ticker = "SAN"
print(ticker)
print(type(ticker))
Resultado
SAN
<class 'str'>

Que una cadena contenga cifras no la convierte en un número. Por ejemplo, "102.50" sigue siendo texto porque está entre comillas. Esta diferencia es importante cuando los datos proceden de formularios o archivos.

Recuerda: 102.50 es un número, pero "102.50" es texto. Las comillas cambian el tipo del valor.

7. Convertir un tipo de dato

A veces recibimos un número escrito como texto. Si intentamos multiplicar directamente "98.75" por otro número, Python no lo interpretará como un precio. Antes de utilizarlo en un cálculo tenemos que convertirlo.

int() convierte a entero, float() convierte a decimal y str() convierte a texto. En el ejemplo siguiente, las dos primeras variables son cadenas y las convertimos antes de calcular el valor de la posición.

Código
precio_texto = "98.75"
acciones_texto = "20"

precio = float(precio_texto)
acciones = int(acciones_texto)
valor_posicion = precio * acciones

print(valor_posicion)
Resultado
1975.0

Después de las conversiones, precio es un float y acciones es un int. Ya podemos multiplicarlos y obtener 1975.0.

La conversión solo funciona si el contenido es compatible. float("98.75") es válido, pero float("precio") produce un error porque la palabra precio no representa un número.

8. Ejemplo completo: resultado de una operación

Ya podemos combinar lo aprendido para calcular el resultado de una compraventa. Primero guardamos todos los datos y después calculamos el coste, el ingreso, el beneficio y la rentabilidad.

Dividir el proceso en pasos hace que el código sea más fácil de seguir. Además, cada resultado intermedio queda guardado y puede revisarse por separado si el resultado final no es el esperado.

Código
precio_compra = 48.60
precio_venta = 51.15
numero_acciones = 80
comision_compra = 1.50
comision_venta = 1.50

coste_total = precio_compra * numero_acciones + comision_compra
ingreso_total = precio_venta * numero_acciones - comision_venta
beneficio = ingreso_total - coste_total
rentabilidad_pct = beneficio / coste_total * 100

print("Beneficio:", round(beneficio, 2), "€")
print("Rentabilidad:", round(rentabilidad_pct, 2), "%")
Resultado
Beneficio: 201.0 €
Rentabilidad: 5.17 %

El coste total incluye la comisión de compra, mientras que el ingreso total descuenta la comisión de venta. La diferencia entre ambos es el beneficio neto. Finalmente, dividimos ese beneficio entre el coste total y multiplicamos por 100 para expresarlo como porcentaje.

9. Depuración de errores

Cometer errores forma parte de programar. El proceso de encontrar la causa de un error y corregirla se conoce como depuración o debugging.

Cuando Python no puede ejecutar una instrucción, muestra un mensaje que ayuda a localizar el problema. Una causa muy habitual al empezar es escribir de forma diferente el nombre de una variable.

Código con error
precio_entrada = 100
print(precio_entrda)
Mensaje de error
NameError: name 'precio_entrda' is not defined

Ante un mensaje de error, conviene empezar por la última línea: normalmente contiene el tipo de error y una breve descripción. Después podemos volver a la línea señalada y revisar nombres, símbolos y tipos de datos.

NameError indica que ese nombre no está definido. En este caso falta una letra en precio_entrda. Basta con corregirlo y volver a ejecutar el código:

Código corregido
print(precio_entrada)
Resultado
100

Un error no significa que haya que empezar de nuevo. Normalmente basta con leer el mensaje, corregir una pequeña parte del código y volver a ejecutarlo.

Resumen

  • print() muestra texto, números y resultados.
  • Python permite realizar operaciones aritméticas y controlar su orden con paréntesis.
  • # inicia un comentario.
  • = asigna un valor a una variable.
  • Los tipos básicos son int, float, bool y str.
  • type() consulta un tipo; int(), float() y str() convierten valores.
  • round() redondea un número.
